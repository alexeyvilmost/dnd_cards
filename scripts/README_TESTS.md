# Тестирование DND Cards системы

Этот набор скриптов предназначен для автоматического тестирования всех основных функций бекенда и фронтенда после внесения изменений.

## 📋 Доступные скрипты

### 1. `test_backend.py` - Тестирование бекенда
Проверяет все основные API endpoints:
- **Health endpoint**: `/api/health`
- **Auth endpoints**: регистрация, логин, профиль пользователя
- **Cards endpoints**: получение, создание, обновление, удаление карт
- **Groups endpoints**: работа с группами
- **Characters endpoints**: работа с персонажами (v1 и v2)
- **Images endpoints**: библиотека изображений и редкости

### 2. `test_frontend.py` - Тестирование фронтенда
Проверяет основные аспекты фронтенда:
- **Основные страницы**: главная, библиотека карт, создание карты, персонажи, группы, авторизация
- **Статические ресурсы**: favicon, логотипы, изображения
- **API подключение**: возможность фронтенда обращаться к бекенду
- **Адаптивный дизайн**: viewport meta теги, mobile-first подход
- **Производительность**: время загрузки страниц

### 3. `test_full_stack.py` - Полное тестирование
Запускает все тесты и проверяет интеграцию между фронтендом и бекендом.

### 4. `run_tests.bat` / `run_tests.sh` - Удобные запуски
Интерактивные скрипты для выбора типа тестирования.

## 🚀 Как использовать

### Windows:
```bash
cd scripts
python test_backend.py        # Только бекенд
python test_frontend.py       # Только фронтенд
python test_full_stack.py     # Полное тестирование
run_tests.bat                 # Интерактивный выбор
```

### Linux/macOS:
```bash
cd scripts
python3 test_backend.py       # Только бекенд
python3 test_frontend.py      # Только фронтенд
python3 test_full_stack.py    # Полное тестирование
./run_tests.sh                # Интерактивный выбор
```

## ⚙️ Параметры

Все скрипты поддерживают параметры командной строки:

```bash
# Изменение URL бекенда
python test_backend.py --url http://localhost:8080

# Изменение URL фронтенда
python test_frontend.py --url http://localhost:3000

# Изменение обоих URL
python test_full_stack.py --backend http://localhost:8080 --frontend http://localhost:3000
```

- ⚠️ **Предупреждения** - желтый восклицательный знак

## 🔧 Требования

- Python 3.7+
- Библиотека `requests`: `pip install requests`
- Запущенные сервисы (бекенд на :8080, фронтенд на :3000)

## 📝 Рекомендации по использованию

### После внесения изменений:
1. **Быстрая проверка**: `python test_full_stack.py`
2. **При проблемах с бекендом**: `python test_backend.py`
3. **При проблемах с фронтендом**: `python test_frontend.py`

### В CI/CD:
```bash
# Проверка перед деплоем
python test_full_stack.py
if [ $? -ne 0 ]; then
    echo "Тесты провалены, деплой отменен"
    exit 1
fi
```

### Регулярное тестирование:
```bash
# Запуск каждый час через cron
0 * * * * cd /path/to/scripts && python test_full_stack.py >> test_logs.log 2>&1
```

## 🐛 Отладка

Если тесты проваливаются:

1. **Проверьте, что сервисы запущены**:
   ```bash
   curl http://localhost:8080/api/health  # Бекенд
   curl http://localhost:3000             # Фронтенд
   ```

2. **Проверьте логи контейнеров**:
   ```bash
   docker-compose logs backend
   docker-compose logs frontend
   ```

3. **Запустите тесты с подробным выводом**:
   ```bash
   python test_backend.py --url http://localhost:8080
   ```

## 📈 Расширение тестов

Для добавления новых тестов:

1. **В `test_backend.py`** - добавьте новые методы в класс `BackendTester`
2. **В `test_frontend.py`** - добавьте новые методы в класс `FrontendTester`
3. **В `test_full_stack.py`** - добавьте вызовы новых тестов

Пример добавления теста:
```python
def test_new_feature(self):
    """Тестирует новую функцию"""
    self.log("Тестирование новой функции...", "INFO")
    result = self.test_endpoint("GET", "/api/new-feature", 200)
    self.test_results["NEW FEATURE"] = result
    return result
```
