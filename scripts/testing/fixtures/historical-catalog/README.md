# Публичные исходные данные исторического теста

Четыре неизменяемых набора восстановлены из подлинных сохранённых исходных
данных. `manifest.json` содержит контрольные суммы исходных файлов и их
публичных проекций; загрузчик дополнительно фиксирует checksum самого manifest.
Все оставленные значения взяты из фактических строк. Условия миграций только
проверяют эти значения и никогда не генерируют их.

| Набор | Строки | Назначение |
|---|---:|---|
| pre278 | 1575 | 1605 исходных условий существующих сущностей до 278 |
| pre279 | 2374 | 2374 исходных условий существующих сущностей до 279 |
| caster296 | 42 | Исходные поля классов и эффектов для 296 |
| cardMembership | 1011 | 886 активных и 125 ранее удалённых предметов |

Авторство, поддержка, сертификаты, личные идентификаторы, даты создания/обновления,
промпты и необязательные URL изображений исключены. `token_storage_id` оставлен:
он входит в исходные условия 279 и обозначает ссылку на ресурс, а не секрет.
Идентификаторы и реальные даты удаления принадлежат исходному публичному каталогу.
Объединение идентификаторов вычисляется из двух исходных наборов, без отдельной
дублирующей копии. Суммарный размер gzip-файлов — 1 370 027 байт.

Наборы предназначены для изолированного исторического теста. Они не являются
production bootstrap или доказательством прежнего процесса выдачи сертификатов.
Полный локальный прогон с этими данными выполнен до 307 и повторён с точным
сохранением всех строк. Сам адаптер прогона пока остаётся в `outputs`; обязательный
штатный migration-профиль ещё требует интеграции. Подлинные архивные значения
отменённых сертификатов используются отдельно только в защищённом локальном тесте;
их нет в этих опубликованных наборах.

После подготовки этого набора на ПК найден подлинный полный архив
`catalog-mechanics-20260929.dump` до 278; он принял все 1656 исходных условий
и неизменённые 277/278 с точным повтором. См.
`docs/audits/2026-10-04/execution/TEST-05-found-pre278-source-20261007.md`.
Происхождение уже зафиксированных наборов и прежних прогонов не изменено.
При изменении набора нельзя
подставлять значения из ожидаемого manifest или текущего каталога: требуется новое
подлинное исходное доказательство и повторный полный прогон.

## Проверка исходных условий

`scripts/testing/historical-catalog-preconditions.mjs` читает исходные manifest 278/279 относительно своего модуля и выполняет только SELECT через переданный `query(sql)`. Вызывающий локальный runner задаёт owned connection и read-only transaction. Проверка требует точную предыдущую границу журнала, включает условия вставок и ожидаемый размер каталога; результат `passed` не означает выполнения миграций или прохождения полного fresh install. Она проверена на двух подлинных локальных архивах: [результаты](../../../../docs/audits/2026-10-04/execution/TEST-05-maintained-preconditions-20261007.md).
