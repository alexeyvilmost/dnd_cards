# Архивные входы отзыва сертификации

Три записи непосредственно скопированы из сохранённых preimage миграций 102,
103 и 119. Полные `prior_support` и `prior_mechanics` не изменены. Проверены
отсутствие персональных полей, адресов и секретов; все примечания уже присутствуют
в отслеживаемых публичных исходниках. Checksum исходного dump, извлечённых файлов,
принятого локального прогона 303 исходных миграций и каждой записи сохранены в manifest.

Это **отозванные исторические сертификаты**, вход только для явного тестирования
исходных revocation migrations. Они не являются действующей сертификацией, не
разрешают replay старого сертификата и не используются при production bootstrap.
Обычные публичные catalog fixtures по-прежнему исключают поддержку и сертификаты.

Загрузчик проверяет неизменяемые байты manifest и gzip, полный набор трёх записей,
их исходные значения и отсутствие приватных полей. PostgreSQL-проверка их исходных
preimage hashes и исполнения оригинальных миграций остаётся отдельным обязательным
этапом полного исторического профиля; сам загрузчик не подтверждает fresh install.
