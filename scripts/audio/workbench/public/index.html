ИСТОЧНИК ЗВУКА

Звуки из ElevenLabs

На сайте ElevenLabs один запрос предлагает четыре варианта. В API один запрос возвращает один файл — студия объединяет четыре запроса в набор для сравнения.

Генерация через открытый ElevenLabs

Нажмите «Заказать 4 варианта» или «Перегенерировать». Запрос сохранится в локальной очереди. Codex выполняет его в открытом браузере и добавляет четыре файла в галерею.

Сама галерея не управляет браузером. После завершения работы Codex новые запросы будут ждать продолжения в чате. API-ключ для этого режима не требуется.
