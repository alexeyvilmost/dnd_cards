# Historical executable corpus v1

Это синтетический локальный replay corpus, а не сертификат ручной проверки сущностей.

- `artifact.cjs.gz` построен из неизменяемого Git tree `4549fb3c903659d3fe2beb272f7f903a731f7388`.
  `manifest.json` содержит SHA-256 распакованных и сжатых байтов, версию esbuild и hashes всех 263 исходников.
- `corpus.json.gz` содержит девять настоящих ответов этого executable: две сохранённые проверки
  (успех и провал), их продолжения, короткий отдых, инициализацию боя и три хода с RNG.
  Данные взяты из существующего синтетического pinned Fighter, поля изображений и аккаунта очищены.
- Текущий HTTP worker должен после перезапуска дважды воспроизвести каждый запрос закреплённым
  старым executable с тем же полным outcome hash. Отдельно проверяется event journal replay.
  Отсутствующий или повреждённый архив должен отказать, а не использовать новую версию правил.
- Это не доказательство совместимости всех фаз/исторических релизов. Paid roll-influence,
  БД receipt/journal и восстановление PostgreSQL проверяет отдельный REL-06 drill.

Обновление этого каталога запрещено генераторами. Для другого исторического executable нужен новый
каталог/manifest. Ручные команды `build-historical-worker-fixture.mjs` и
`build-historical-replay-corpus.mjs` создают файлы только один раз; повтор допускается только с
побайтово одинаковым результатом. Обычный тест не обращается к Git, внешней сети или рабочей БД.
