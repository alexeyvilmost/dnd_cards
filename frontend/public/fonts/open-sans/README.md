# Open Sans

Unmodified Latin and Cyrillic WOFF2 subsets, normal style, weights 400, 600 and 700.
Served locally for the paper character sheet as the CSS family `Paper Open Sans`.

- Source: https://fontsource.org/fonts/open-sans
- Package: `@fontsource/open-sans` version `5.3.0`
- Archive: https://registry.npmjs.org/@fontsource/open-sans/-/open-sans-5.3.0.tgz
- Archive SHA-256: `95e6dd90f5860d0de22f791b6d802598743762c62e4894bfa26f80b1ea0cf3f5`
