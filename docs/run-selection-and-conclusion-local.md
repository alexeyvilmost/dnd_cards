# Выбор группы и завершение боя — локальная проверка 18.09.2026

## Интерфейс

- После вводного блока две колонки: начало и продолжение забега; на узком экране — одна.
- Пресеты и свободные личные листы выбираются в общий состав, до шести участников. Группа может состоять из пресетов, личных листов или их сочетания.
- Имена пресетов задаются в общем диалоге. При повторе после ошибки уже успешно созданные копии с тем же именем переиспользуются в пределах открытой страницы.
- Строки показывают имя, вид, класс и уровень из каталогов. Забеги показывают всех участников, фазу и краткий прогресс.
- Объяснение выбора перенесено в общий HoverCard у «?», без HTML title; описание также доступно через ARIA.
- Сервер возвращает занятые исходные листы по **всем** активным забегам пользователя, отдельно от ограничения 50 записей истории. Проверка допустимости состава на сервере сохранена.

## Бой

- Смерть любого управляемого участника (флаг смерти, три провала или канонический terminal lifecycle) имеет приоритет над победой.
- После завершения всех решений каждый выживший участник с 0 HP получает 1 HP, со сбросом спасбросков. Мёртвые и противники не восстанавливаются.
- Восстановление выполняется на внешней границе команды, не внутри шага движения, предварительного броска или сбора реакций. Оно записывается в журнал; повторная финализация не лечит повторно.
- Подтверждённый смертельный спасбросок остаётся в своём диалоге до закрытия. Затем trusted worker ставит outcomeFinalized, и API атомарно сохраняет поражение забега и листы. Награда за поражение не выдаётся.
- Для новых встреч worker использует `sha256:3fbcef3398e37fc7b2298d1b8158f194a419dabb12e207376d549adb7194d93a`. Существующие встречи сохраняют архивные артефакты и историю. Схема SQL не меняется.
