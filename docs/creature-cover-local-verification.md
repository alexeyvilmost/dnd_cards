# Звук и укрытие существами — локально, 17.09.2026

## Изменения

- Временный общий выключатель `audio/availability.ts`: музыка, эффекты и прослушивание
  не создают аудиопоток даже при сохранённом `audioEnabled: true`.
  Настройки громкости, файлы в Storage и привязки БД сохранены. Настройки объясняют
  временное отключение; анимация лечения остаётся.
- `creatureCoverObstacles`: размер из общего `breakdownValue`, включая модификаторы;
  Tiny/Small — половинное укрытие, Medium и крупнее — непрозрачное препятствие
  для атаки. Геометрия использует полный footprint и существующие лучи к углам цели.
  Союзники и враги равнозначны. Источник, цель и существа с HP ≤ 0 исключены,
  как в расчёте занятости клеток. Укрытия не складывают бонусы.
- Визуальная видимость не исчезает из-за тела: полное укрытие проверяется отдельно
  авторитетным исполнителем. Предпросмотр КД, траектория, подход игрока, планировщик
  монстра и продолжение многоатаки учитывают новое укрытие.
- Новые встречи имеют `creatureCoverVersion: 1`. Отсутствие маркера сохраняет
  прежнюю геометрию UI у старых встреч; их закреплённый артефакт не заменяется.
