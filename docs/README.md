`testing-suites.md` заменяет старые общие команды Python testing и трактовку compile-only Go как полной проверки. `scripts/testing/README.md` заменяет исторические инструкции с постоянной локальной QA БД для автоматических тестов. `roguelike-local-development.md` остаётся описанием ручного dev workflow; адреса и snapshots из его датированного примера не используются новым runner.

Документы `*-local-verification*`, датированные аудиты, планы прошлых этапов и `audits/*/execution` — доказательства конкретного прогона. Их показатели нельзя переносить на текущий commit. `knowledge-base.md` содержит исторический реестр; его замечания сопоставляйте с датой, текущими исходниками и новой проверкой. Старые записи о поддержке сущностей не заменяют ручной статус в БД.

Результаты новых запусков хранятся под `outputs/`; исходные изображения и локальные сравнительные checkout из `output/` и `tmp/` сохранены и исключены из нового untracked discovery. Отслеживаемые Git файлы в этих каталогах по-прежнему проверяются. Сводные безопасные evidence переносятся в `audits/<date>/execution`; credentials, личные снимки и raw entropy остаются вне Git.

Перенос архивной документации должен сохранять старые ссылки и проверять `?raw`, динамические imports, `go:embed`, генераторы fixtures и skill references. Возраст документа сам по себе не основание для удаления.
