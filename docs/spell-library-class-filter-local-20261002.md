# Фильтрация заклинаний по классу: локальная проверка

UI библиотеки отправляет устойчивые обозначения `wizard`, `cleric` и т. д. Конструктор также сохраняет такие значения, тогда как импортированный каталог использует локализованные названия (`волшебник`, `жрец`). Прежний поиск подстроки `classes::text ILIKE` пропускал этот второй формат.

Фильтр теперь получает соответствия из записей основных классов: `name`, `name_en`, `card_number`, его суффикс и UUID. Он сопоставляет отдельные элементы `classes[]` после нормализации регистра и пробелов. Отдельного списка переводов, изменения механик или миграции содержимого нет. Неизвестный класс сопоставляется буквально, `%` и `_` не расширяют результат. Фильтрация выполняется до подсчёта и пагинации.

Проверки:

- Backend: адресные `TestSpellClassReferenceAliasesComeFromClassData`, `TestSpellListClassFilterResolvesCatalogAliasesBeforePagination`, `TestSpellListClassFilterMatchesUnknownLabelsLiterally` и существующий `TestSpellListRetainsOnlyVariantParentMetadata` прошли с настоящим локальным PostgreSQL в изолированных временных схемах. Проверены два разных класса, смешанный формат, регистр, страницы полного и облегчённого каталога, комбинация уровня и поиска, неизвестные метки и исключение подклассов из разрешения основного класса.
- Frontend: `CardLibrary.test.tsx` и `libraryUrlParams.test.ts`, всего 25 тестов, прошли. Проверены смена/сброс класса, сохранение остальных фильтров, замена прежней выдачи и класс следующей страницы.
- TypeScript `tsc --noEmit`, адресный ESLint и проверка пробелов в diff прошли.
- Реальный локальный UI на снимке `shop_review_249_20260915`, только чтение: жрец — 117, волшебник — 244, паладин — 51, бард — 140 заклинаний. Волшебник + 1 уровень + Прорицание + Ритуал — 3 результата; добавление «без концентрации» — 2; поиск «Опознание» — 1. После перезагрузки фильтры и выдача из 3 заклинаний сохранились.

Для проверки использован отдельный API `127.0.0.1:8081` с read-only соединением и frontend `127.0.0.1:3001`; существующий сервис на 8080 не менялся. В production изменения не применялись. Данные заклинаний и статусы проверки не изменялись.
