# Бумажный лист: перенос, кузница и повышение уровня

Доработка от 2 октября 2026. Публикация выполняется из проверенного коммита по [инструкции выпуска](standalone-deploy-after-push.md).

## Открытие

- На интерактивном листе кнопка «В бумажный лист» создаёт отдельный редактируемый документ. В мобильном интерфейсе она находится в разделе «Ещё → Лист персонажа».
- Новый конструктор: `/paper-sheet/create`.
- Кузница сохранённого листа: `/paper-sheet/:id/forge`.
- Повышение уровня: `/paper-sheet/:id/level-up`.

Переход с бумажного листа сначала дожидается сохранения всех текущих правок. Ошибка или конфликт версий оставляет пользователя на листе с его черновиком. Черновики кузницы и повышения уровня сохраняются отдельно для каждого документа и его ревизии; перезагрузка не повышает уровень повторно.

Кузница переиспользует обычные сборщики, проверки выбора, мультикласс, подготовку заклинаний и каноничные превью. Бумажный вариант имеет белый фон, простые границы и компактную навигацию. Его сохранение обращается только к API бумажных документов, без создания или изменения интерактивного персонажа. Авторизованному пользователю создаётся лист аккаунта; гостю — анонимный лист со ссылкой доступа.

## Перенос и сохранение

Перенос читает свежий интерактивный персонаж и связанные библиотечные данные. Сохраняются происхождение и выборы развития, характеристики, владения, способности, подготовленные и известные заклинания, инвентарь с количествами, снаряжение, настройка, монеты, портрет и заметки. Текущие хиты, временные хиты, спасброски от смерти и израсходованные ресурсы не восстанавливаются отдыхом. Предметы продолжают использовать общий расчёт снаряжения: их бонусы не записываются повторно в базовые характеристики.

Временные эффекты переносятся как читаемый снимок. Бумажный документ не исполняет боевые команды. Ошибка загрузки обязательной сущности или вложенного эффекта предмета останавливает перенос до создания документа. Переполнение табличных ограничений также вызывает явную ошибку вместо потери записей.

При повышении уровня изменяются автоматически созданные значения, которые пользователь не правил. Ручные формулы, заметки, снаряжение, количества, монеты и текущие ресурсы сохраняются. Заменённые автоматические заклинания и ссылки на способности обновляются; отредактированная строка удалённого из сборки заклинания остаётся с пояснением.

## Совместимость

Основной формат остаётся `PaperSheetDocument.version = 1`. Новое необязательное поле `progression` содержит переносимый черновик кузницы без ID исходного интерактивного персонажа и снимок автоматически заполненных полей. Старые документы без этого поля продолжают открываться и редактироваться. Перед первым повышением уровня такого документа нужно проверить происхождение и завершить выборы в кузнице; отсутствие старых выборов не угадывается.

JSON Bag of Holding сохраняет данные развития. Экспорт LSS содержит необязательное расширение `bohProgression`, позволяющее восстановить наши выборы, ссылки и исходные формулы при обратном импорте. Обычные файлы LSS без расширения сохраняют прежнее поведение; числовые изменения, сделанные в LSS, имеют приоритет при импорте.

## Локальная проверка

Используется изолированный API документов на `127.0.0.1:8082`, база `paper_sheet_20261002_qa`. Каталоги доступны только для чтения, обращения к внешним HTTP-сервисам отключены. Frontend открыт на `127.0.0.1:3000`.

На реальных локальных каталогах проверены две разные сборки: воин и волшебник. Для каждого создан новый бумажный документ, выполнены два повышения уровня, повторное чтение сохранённой ревизии, импорт/экспорт JSON Bag of Holding и LSS. Ручные хиты, формула инициативы, журнал, количество предметов, снаряжение и монеты сохранены. Отдельный старый документ версии 1 прочитан без добавления данных развития и без изменений содержимого.

Итог: 291 тест в 25 связанных файлах прошёл; TypeScript, адресный ESLint, Vite/PWA и обе проверки ресурсов DiceBox прошли. Расширенный прогон интерактивного листа: 1050 успешных тестов, 4 сбоя. Все четыре воспроизведены на отдельной копии исходного HEAD `70970f5`: два теста сертификации боевого каталога, один тест продолжения спасброска и один тест касания через спутника. Их исходники и боевой движок этой доработкой не менялись.
