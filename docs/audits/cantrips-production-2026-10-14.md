# Аудит заговоров production — 14 октября 2026

Проверены все 84 записи уровня 0 в свежем [продовом каталоге](https://bagofholding.ru): 35 основных заговоров и 49 вариантов. Каталог прочитан 14.10.2026 в 13:10:27 МСК через публичные GET API с проверкой всех страниц. Это экспорт каталога, а не транзакционный снимок всей БД. Этот раздел описывает состояние до выпуска; результат выкатки записывается отдельным дополнением.

34 основных заговора сверены с английским оригиналом **Player’s Handbook 2024**, включая рост на 5/11/17 уровнях, условия, ограничения, метаданные и выбранные варианты. Номера ниже — печатные страницы книги. Локальные файлы в `officials/kb/phb-2024-en/pages` имеют номер на единицу меньше; например, книга стр. 334 → `page-333.txt`. Продовые описания относятся к редакции 2024; правила 2014 не подмешивались.

Авторский «Астральный рывок» (`SPELL-0482`, источник Bag of Holding) отсутствует в книге. Он включён в аудит, но не объявлен соответствующим оригиналу и не переписан на основании выдуманного источника.

## Подготовленные локальные изменения

- 83 записи: исправлены сокращённые/полные описания, смысловые абзацы, ссылки и цвет с иконками типов урона. Во всех 49 вариантах текст описывает конкретный выбор. Из 43 отсутствовавших полных описаний заполнены 42; оставшееся принадлежит авторскому заговору.
- Добавлено понятие «МЗ» и каноничная ссылка `concept:spellcasting_modifier` вне контекста персонажа. При известном модификаторе в формуле показано только число. Исполняемый идентификатор по-прежнему `spellcasting`.
- Общий компонент формул используется превью заклинаний, действий, эффектов и предметов. Полезные короткие выражения видны сразу; неразрешённые функции/служебные идентификаторы показаны словом «Формула». Полное выражение доступно в стандартном hover-превью, при фокусе клавиатуры и по нажатию.
- Для выпуска правки оформлены отдельным SQL-пакетом `database/cantrip_editorial_20261014.sql` после принятия релиза. Новых стартовых миграций или постоянного DDL нет. Пакет сверяет UUID, номер карточки, имя, уровень, текущие тексты и механику; при расхождении прекращает всю транзакцию. Старые строки и квитанция сохраняются в существующих таблицах аудита 307. Повтор не дублирует изменение. Механики, статусы проверки, исторические каталоги, персонажи и боевые журналы не обновляются. Первоначальный локальный прототип 308–309 в выпуск не включён.

## Оставшиеся проблемы превью

Это подтверждённые результаты аудита, требующие отдельной доработки общего сборщика статистики. Редактура текста не должна маскировать их или менять механику.

| Приоритет | Сущность/случай | Наблюдение и требуемое поведение |
|---|---|---|
| P1 | Погребальный звон | `parseMechanicsStats` выводит взаимоисключающие 1к8 и 1к12 как сумму. Показывать альтернативы с условием полноты хитов, используя `when` из данных. |
| P1 | Рост заговоров в контексте персонажа | Превью читает базовую кость и не применяет `scaling`. На локальной проверке персонажа 5 уровня вариант Чародейского выброса показывает 1к8 вместо 2к8. Использовать каноничный расчёт масштабирования. |
| P2 | Чародейский выброс, основной заговор | Урон внутри `choice.options.items.grants` не попадает в статистику. Показать альтернативные типы общей кости без сложения. |
| P2 | Меткий удар, варианты | Сборщик не учитывает `omit_if_zero` и не раскрывает оружейную кость без контекста. Нулевая прибавка Излучения не должна выглядеть отдельным уроном. |
| P2 | Сотворение пламени | Статистика берёт легаси-урон 1к8 как результат бонусного сотворения, хотя атака предоставляется отдельным действием. Показать свет/предоставляемую атаку и её стоимость. |
| P2 | Мистический заряд | 1к10 относится к одному лучу. При контексте персонажа явно отражать число лучей и отдельных атак из `target_slots_by_character_level`. |
