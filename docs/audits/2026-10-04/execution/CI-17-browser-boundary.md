# Ожидание ответа перемещения в браузерном тесте

CI17 `37394798624` коммита `7d580ae0` прошёл backend, unit и flows, но отказал на проверке доступности атаки в расширенном браузерном сценарии. Эмулятор регистрировал полученный PATCH раньше, чем браузер применял ответ; однократный поиск мог застать отключённые действия.

Тест теперь ждёт реальной доступности каноничного действия, сохраняя проверки результата, ресурсов и боеприпасов. Локальный полный сценарий создания персонажа → лист → бой прошёл на настольном и мобильном экранах: два теста без задержки и два с задержкой ответа на 500 мс. Оба временных стенда остановлены; исходники во время проверок не менялись. Это проверка UI на изолированных ответах API, отдельно от реальных API/worker сценариев CI.

Дополнительное локальное сравнение пакетного каталога завершило 344 боя, включая 320 измерений. Для группы из шести: 183→44 SQL, медиана 393,6→372,9 мс, p95 864,4→646,1 мс. Для одного персонажа выигрыш небольшой; у двух p95 вырос на 0,18%. Это одна серия тестового API с tracing, без доказательства полного UI или production ускорения. Batch, mirrors, cache и native SHA остаются OFF.
