Через предоставленный пользователем Sota успешно выполнены GET моделей и **одна реальная генерация** `gpt-image-1`: HTTP 200, PNG 1024×1024, качество low, около 11 секунд, без повторов. Проверялся провайдер с TimeWeb; новый backend ещё не выложен и его production endpoint этим запросом не проверялся.

- Migration 300; durable owner-scoped jobs, лимиты, атомарный результат и ссылка сущности, повтор того же ID, terminal unknown без повторного paid POST.
- История в ImageStudio с обновлением и страницами по 20 заданий; клиентский ID переживает reload, session change отсекает старый ответ, abort отменяет только ожидание, недоступное localStorage останавливает отправку.

Старые неопределённые синхронные попытки получают отдельную локальную квитанцию; переход на jobs не снимает блокировку повтора.

## Изоляция сетевого сбоя

Обязательный gate `image-egress-isolation` прошёл на настоящих PostgreSQL, Go-контроллере и Node worker: 3 игровые команды и 3 точных повтора, 18 обращений к worker только при первом исполнении команд. Пока CONNECT-запрос генерации удерживался и затем завершался сетевой ошибкой, игровая команда и отдельная S3-загрузка успешно выполнялись. После восстановления отдельный новый запрос генерации прошёл. Ключ не попал в CONNECT, TLS проверялся, прямых обходных запросов и автоматических повторов не было. Provider и S3 — локальные протокольные имитаторы, внешних платных запросов — ноль. [Результат](AI-03-egress-isolation.json).

На TimeWeb запущен постоянный Sota gateway с выходом через Финляндию и автоматическим запуском после перезапуска сервера. Он принимает только авторизованные CONNECT к `api.openai.com:443`; локально проверены 407 без пароля и разрыв TLS для другого сайта. Сервис работает непривилегированно без внешних портов и изменений маршрутов хоста. [Повторная проверка постоянного сервиса](AI-03-sota-permanent-provider-probe.json) получила 200; временные контейнеры удалены. Мастер-ключ Sota остался локальным. Подготовлено отдельное защищённое окружение следующего backend; работающий backend ещё не переключён. Поддерживаемое размещение проверяется по [официальному перечню](https://developers.openai.com/api/docs/supported-countries); значение 403 — по [справочнику ошибок](https://developers.openai.com/api/docs/guides/error-codes).
