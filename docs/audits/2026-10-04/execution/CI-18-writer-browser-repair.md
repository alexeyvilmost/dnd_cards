# CI18 и исправление запуска браузера публикации

Полный CI18 коммита `4336325a` прошёл: 936 Node, 6462 Vitest, 754 обязательных случая Go, 25 DB/worker, 48 UI, 8 battle3D и 12 основных браузерных сценариев, без обязательных пропусков. Проверка длилась 879542 мс; все её стенды остановлены. [Фактический запуск](https://github.com/alexeyvilmost/dnd_cards/actions/runs/37396343027).

[Публикация 37397903525](https://github.com/alexeyvilmost/dnd_cards/actions/runs/37397903525) собрала, проверила и отправила три образа, затем отказала на проверке браузера новых форматов. Артефакт кандидата не опубликован, настройки и версия сервера не менялись. Старый обработчик скрывал исходную причину отказа.

В локальном Linux воспроизведён аварийный выход Chromium: путь временного Unix-сокета под глубоким каталогом доказательств превысил допустимую длину. Такой же риск присутствует в пути hosted workflow; это вывод из воспроизведения, а не извлечённая причина исходного запуска. Исправление использует короткий закрытый каталог `/tmp/wb-*`, проверяет его владельца перед очисткой и очищает его после отказа запуска. Публикация теперь сообщает только фиксированное имя этапа отказа, без исходного текста ошибки и секретов.

Исправленный нативный Linux-процесс выполнил обе пары фактических OCI-образов: текущий и прежний фронтенд, сохранённое задание после перезагрузки, переход ON→OFF и повтор принятого запроса без второго обращения к эмулятору провайдера. Два стенда остановлены. Это локальная проверка, без права на выкатку и без подмены происхождения CI. Linux-контроллер использовал Node 24.18.1; hosted workflow закреплён за 24.19.0. Первичное копирование доказательств в Windows отказало на созданной браузером символической ссылке; JSON-доказательства восстановлены из сохранённого тома только чтением, исходная неудачная запись сохранена. Проверка первой версии исправления дала 458 PASS и 5 окружение-зависимых пропусков; окончательные связанные проверки — 12 PASS без пропусков. Секреты, дампы и формат diff проверены.

Парное измерение реального экрана от кнопки лагеря до отрисованных строк инициативы завершило 68 боёв, из них 60 измеряемых. Для одного персонажа медиана OFF→batch выросла 298,2→304,8 мс; для шести уменьшилась 706,3→672,5 мс, но p95 вырос 960,8→991 мс. По 15 измерений на вариант: p95 предварительный. Общего выигрыша интерфейса не доказано, batch остаётся OFF.

Прод остаётся на `93265633`, новые writers, selective и auto выключены. Резервные копии по решению владельца пока хранятся на основном сервере.
