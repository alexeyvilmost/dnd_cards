# Актуальное измерение экипировки, 7 октября

Серверную подготовку экипировки и экспериментальную сортировку ID пока не включаем: общего улучшения задержек не доказано. Проведены 372 настоящие операции через браузер, локальный API и каноничный движок правил: 360 измерений и 12 прогревов. Ошибок браузера нет, ревизии/размещение/ёмкость ресурса проверены, исходные персонажи не изменены; все три стенда завершены с очисткой временных процессов без ошибок.

p50 — медиана, p95 — граница, в которую укладываются 95% измерений. OFF — текущий путь, ON — серверная подготовка экипировки.

У ON улучшилась медиана ресурсного предмета, но обычные операции замедлились и p95 не улучшился. В медленных примерах подготовка интерфейса занимала около 580–600 мс, тогда как серверная команда — около 75–125 мс. Асинхронные каноничные проекции и чтения карточек присутствуют в этих интервалах; причина конкретного плана PostgreSQL/JIT ещё не проверена.

Одна локальная строка со стабильным порядком ID прошла две проверки TypeScript, production-сборку и 3 теста доступности. Сравнение 120 измерений также не показало общего выигрыша; правка отменена, её patch/сборка/исходные отчёты сохранены. Она не используется для искусственного доказательства frontend-only выкатки.

Применены те же native backend/CJS, fixtures и флаги batch/mirrors/compact ON, cache/prefetch/frozen OFF; initiative options ON во всех сериях. Код backend/frontend/testing/performance между исходной сборкой D8 и текущим 05085 одинаков. UI сортировки — отдельная непубликовавшаяся сборка. Это последовательные локальные серии по 30 измерений на сценарий, а не парный причинный эксперимент, Linux OCI или SLA прода. Повтор/RNG/права/pending проверяются отдельными текущими CI-сценариями; это измерение не подменяет их. Платных запросов и изменений продовой БД нет.
