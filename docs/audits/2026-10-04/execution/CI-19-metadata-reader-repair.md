# CI19 и устойчивое чтение метаданных публикации

Полный [CI19 коммита `49770e6f`](https://github.com/alexeyvilmost/dnd_cards/actions/runs/37400517906) прошёл: 938 Node, 6462 Vitest, 754 обязательных случая Go, 25 DB/worker, 48 UI, 8 battle3D и 12 основных браузерных сценариев, без обязательных пропусков. Интервал — 808607 мс; все стенды остановлены.

[Публикация 37401922384](https://github.com/alexeyvilmost/dnd_cards/actions/runs/37401922384) проверила и отправила три образа, но отказала на `predecessor-refresh` до запуска браузера. Кандидат не опубликован, профиль сервера не активирован, выкатка не запрашивалась. Диагностика исходного запуска ещё не сохраняла HTTP-статус или вид сетевой ошибки, поэтому причина этого конкретного отказа не утверждается.

Проверка GitHub с локальным read-only доступом подтвердила неизменность принятого predecessor после 102 чтений метаданных. Новый обработчик ограничивает временные сетевые ошибки тремя GET-попытками, сохраняет безопасные числовые сведения об отказе и не читает тело ошибочного ответа. Отказ доступа, длительное исчерпание квоты и некорректный JSON останавливают публикацию; проверки неизменности кандидата и predecessor сохраняются. В реальной локальной проверке произошёл один транспортный сбой: повтор восстановил чтение, итоговый predecessor совпал. Это отдельный локальный доступ, без утверждения о токене завершённого hosted job. 22 связанные проверки прошли без пропусков; секреты, дампы и diff проверены. Исправленный исходник требует нового точного CI.

Более длинная парная серия реального интерфейса завершила 176 боёв, включая 160 измеряемых, по 40 на вариант и размер группы. Для одного персонажа медиана OFF→batch выросла 256,9→259,3 мс, p95 — 282,8→290,6 мс. Для шести медиана уменьшилась 574,8→568,2 мс, p95 вырос 728,7→902,9 мс. p95 остаётся предварительным по правилам измерителя. Поэтому batch остаётся OFF; более узкий выигрыш предыдущей серии API не объявляется общим ускорением интерфейса. Проверены точный повтор, сохранённый бой и неизменность исходных листов; браузер и стенд остановлены.

Прод остаётся на `93265633`, новые writers, selective и auto выключены. По решению владельца backups пока хранятся на основном сервере. Следующий шаг — точный CI исправления, успешная публикация и полная серверная репетиция. [Машинная запись](CI-19-metadata-reader-repair.json).
