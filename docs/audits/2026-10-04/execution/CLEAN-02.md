# CLEAN-02 — сокращение продуктовой поверхности

> Исторический первый этап. 05.10.2026 пользователь прямо разрешил удаление всех версий персонажей кроме V3. V1/V2 API, UI, модели и экспорт удалены; прежний период deprecation больше не требуется. Текущий результат и 11 проверок PostgreSQL: [CLEAN-02-retired-characters](CLEAN-02-retired-characters.md). Старые таблицы пока сохранены для отката первой выкатки. Ниже — состояние до этого решения.

## Реализован обратимый этап

Основная навигация: Библиотека, Персонажи, Бумажный лист, Забег. В дополнительных меню сохранены Профиль, Настройки, Экспорт и добавлена доступная ссылка на Инициативу. Группы, отдельные инвентари и шаблоны карточек скрыты по умолчанию. Настройка «Дополнительные разделы» в разделе «Лист и редактирование» возвращает их без перезапуска и сохраняется в браузере. Это настройка навигации, не разрешений.

Все прежние маршруты и данные сохранены. Пользователь, открывший прежнюю ссылку на инвентарь, не теряет страницу при выключении настройки. Шаблоны персонажей в забегах и мастерство оружия не относятся к скрываемой странице шаблонов карточек.

## Карта зависимостей

| Поверхность | Статус | Зависимости / решение |
|---|---|---|
| `/library`, `/entity/:type/:id`, `/spell/:id`, `/monsters` | kept | Каталоги, каноничные карточки и редакторы сущностей |
| `/characters-forge`, `/character-forge/*`, `/characters-v3/:id` | kept | `characters_v3`, общие сборщики, экипировка, resources, authoritative commands |
| `/paper-sheet/*` | kept | Сохранённые документы, создание, повышение уровня, JSON/PDF |
| `/roguelike/*`, `/characters-v3/:id/combat` | kept | Шаблоны персонажей, магазин, loot, общие правила, receipts/history |
| `/account`, `/settings`, `/export`, `/initiative` | kept | Нужны по запросу пользователя |
| `/groups/*` | hidden | `groupsApi`, Group/GroupMember, Inventory.group_id; восстановление через настройку |
| `/inventory/*` | hidden | `inventoryApi`, Inventory/InventoryItem, группы и прежние персонажи; не путать с inventory_items персонажа V3 |
| `/templates` | hidden | WeaponTemplates и справочники оружия; сами данные и потребители мастерства сохранены |
| `/characters`, `/characters-v2`, `/characters/create` | deprecated UI | Уже существующие redirects в кузницу сохранены; API V1/V2 пока нужны для чтения/экспорта прежних данных |
| `/shop/*`, редакторы сущностей | kept dependency | ShopDetail используется забегами/листом; редакторы обслуживают библиотеку |
| `/m/*`, отдельные encounters, docs, rules-lab | retained pending usage evidence | Отсутствие основной вкладки не доказывает отсутствие потребителей; общий боевой код сохранён |
| Контроллеры/таблицы | deleted: none | Удаление требует доказательств отсутствия внешних callers и плана миграции |

API V1 содержит `GET /characters/:id/export` и `POST /characters/import`; V2 содержит CRUD, inventories, equip, armor и active-effects. Добавлен `GET /characters-v2/:id/export`: владелец может скачать прежнего персонажа из профиля. Архив сохраняет записанные поля листа, ресурсы, эффекты, инвентари и предметы, включая неизвестные расширения и большие целые числа; контрольная сумма относится к точным JSON-байтам payload. Это архив V2, автоматического преобразования механики в V3 нет. Общие `/inventories/*` включают операции предметов и ссылки прежних персонажей. Выключение меню не отключает эти API. Полная механическая инвентаризация зарегистрированных маршрутов записана в `product-surface-inventory.json` рядом с этим документом.

## Проверка и оставшиеся этапы

- 21/21 локальных проверок Layout, SettingsPanel и настроек: основные ссылки, отсутствие скрытых ссылок, включение, повторное монтирование и выключение без потери текущего содержимого.
- Свежая сборка и S01–S10 + review-пагинация: 11/11 PASS, 0 skip/retry, run test_86e66f54dedf2c9f418f9227. Основная навигация и редкие сохранённые разделы проверяются unit/UI fixtures; общий итог extended фиксируется отдельно.
- Метрики реального использования и внешние API callers не измерены: обращения к production не выполнялись. Поэтому контроллеры, таблицы и старые данные не удалены.
- Экспорт V2: 1 обязательная проверка на настоящем PostgreSQL и 3 UI-проверки PASS. Скачанные данные восстановлены во временные таблицы V2 с точным совпадением всех строк; исходные данные не менялись. Проверены чужой доступ, повторное скачивание и смена учётной записи. [Доказательство](CLEAN-02-v2-export.json).
- Для дальнейшего удаления: получить агрегированные счётчики маршрутов без IDs/текста/токенов; проверить внешних callers; согласовать преобразование в V3 при необходимости; выдержать период deprecation; только затем удалять конкретные недостижимые модули. Возраст файла сам по себе не является основанием удаления.

Откат текущего этапа: включить «Дополнительные разделы»; программный откат меняет только настройку и построение меню. Исторические данные не преобразовывались.
