# Ускорение commands: снимок боя, компактный обмен и фоновое сохранение

На проде независимо подтверждён выпуск `30f9f605ff7e`: бэкенд, фронтенд и
worker соответствуют опубликованным образам. Схема БД остаётся на версии 308.
**Предел 200 мс для всех команд пока не достигнут; 100 мс не объявляется SLA.**

Большой ответ движка содержал повторяющиеся состояние, каталоги и снимки
персонажей. Для точного сохранённого кадра следующий запрос теперь передаёт
около 2 КБ вместо 86 КБ, ответ движка — 67–181 КБ вместо примерно 1,8 МБ.
Бэкенд восстанавливает полный результат и проверяет исходный каноничный hash.
Иконки, различия отображения и чужие изменения листа не исчезают. Неизвестная
версия движка возвращается к полному протоколу до исполнения команды.

Повторный расчёт клеток существа объединён только внутри одного неизменного
пространственного наблюдения. Данные и сохранённые исполняемые артефакты
прежних боёв остаются исходными. Сравнение с оригинальным движком проверяет
полный результат, случайность и hashes истории. Браузер хранит четыре приватных
базы восстановления; изменение данных интерфейсом их не повреждает.

Настоящий запрос ждёт уже поставленный в очередь предварительный расчёт,
а новые догадки не вытесняют востребованную работу. Чтение неизменных действий
и эффектов происходит из снимка боя. Запись принятого результата идёт в фоне;
при аварии допустима потеря одной последней команды на забег. Следующая
команда сохраняет проверки владельца и ревизий. При штатном выключении сервер
ждёт сохранения. Повтор одного ID не бросает кубики и не списывает ресурсы вновь.

Замеры выполнены на отдельной копии боя на TimeWeb. Это внутренний HTTP
с восстановлением полного ответа на процессоре сервера; публичная сеть и
рендеринг настоящего браузера сюда не входят. По десять измерений каждой
обычной команды и по три в быстрой серии недостаточны для заявления SLA.

| Команда | Выпуск 5e590fac, медиана / максимум, мс | Выпуск 30f9f605, медиана / максимум, мс |
|---|---:|---:|
| Завершение хода | 175 / 482 | 129 / 710 |
| Спасбросок, первая фаза | 165 / 223 | 108 / 136 |
| Спасбросок, вторая фаза | 161 / 191 | 100 / 147 |
| Спасбросок, третья фаза | 185 / 254 | 116 / 144 |
| Завершение хода в быстрой серии | 426 / 1287 | 405 / 1550 |

Исходный замер завершения хода до этих работ: медиана около 3071 мс.
Основной остаток задержки в быстрых сериях — вычисление непрогретого кадра
и конкуренция с сохранением предыдущей команды. Это требует следующей
измеряемой оптимизации; текущий выпуск не считается завершением этой цели.

На сервере оставлены две полные резервные копии: текущая перед выкаткой и
предыдущая. Более старая проверена и сохранена на ПК; удалён временный dump
завершённой репетиции. Дополнительно освобождено около 2 ГБ.

Следующая локально проверенная оптимизация — использовать ответ загрузки
боя как точную приватную базу первой команды. Токены `read:UUID` отделены от
ID команд; чтение не создаёт квитанции и не изменяет принятую ревизию.
В изолированной локальной проверке размер загрузки уменьшился с 4,36 до
1,83 МБ, первого ответа — с 1,86 до 0,49 МБ. Эти локальные результаты не
объявляются измерением TimeWeb. Выпуск подготовлен к обычным проверкам CI.
