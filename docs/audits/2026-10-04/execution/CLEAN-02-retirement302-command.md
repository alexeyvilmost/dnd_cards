# Проверка исполняемой команды удаления старых персонажей

Добавлена общая граница транспорта для явного выполнения, чтения результата и восстановления потерянного ответа миграции302. Перед отправкой команды она читает `--migration-info` и сверяет происхождение сборки, коммит, fingerprint, поддержку команды, хэш SQL и полный список миграций. Старому бинарнику неизвестный флаг не отправляется. Ответ проверяется существующими валидаторами; восстановление потерянного ответа допускает только пустой список выполненного SQL.

Добавлены15 проверок границ, а все8 наборов тестов удаления включены в обязательный selection-security. Связанные209 проверок прошли на Windows и на настоящем Linux без пропусков. Для Linux подготовлен локальный образ с Node24.21, Git и js-yaml из имеющихся локальных образов; сеть выключена, источник смонтирован только для чтения, список файлов взят из реального checkout. Первый запуск минимального образа завершился пятью ошибками отсутствующих инструментов; ошибки сохранены, набор не сокращён.

Отдельно реальный локальный Go-бинарник вернул неподтверждённое происхождение сборки. Граница транспорта отказала после чтения metadata, не отправив команду миграции. Это отрицательная проверка защиты, а не доказательство выполнения SQL.

Продовая БД не менялась. Приёмка свежего архива и пары образов, подключение к журналу намерения и продовый оператор остаются следующими шагами. [Подробный отчёт](CLEAN-02-retirement302-command.json).
