# Состояние реализации на 6 октября 2026 года

Версия `93265633` выкачена на TimeWeb после полного CI15 и репетиции на копии БД. Независимая проверка подтвердила HTTP200, все три компонента, их версии/образы и 305 записей миграций. Выполнение следующего этапа продолжается; новые writers и автоматическая доставка ещё выключены.

CI15: 731 Node, 6462 Vitest, 754 обязательных случаев Go, 25 DB/worker, 22 проверки истории/курсора, 12 основных браузерных сценариев, 48 UI и 8 battle3D. Измеренный общий интервал — 883148 мс; это один запуск, не постоянная гарантия.

Следующий порядок: точный CI нового исходника → опубликованная проверка новых форматов и браузера → полный серверный релиз → реальная раздельная выкатка и автоматика. Обязательное восстановление, сохранение старой истории и проверка свежести backups продолжают действовать.

Следующий коммит `8633d6f3` прошёл расширенный CI16. Публикация остановилась до сборки из-за потери номера проверенного артефакта в CLI; исправление прошло 40 локальных проверок, новый точный CI обязателен. Рабочая версия остаётся `93265633`. [Подробности](CI-16-publication-handoff.md).

CI17 отказал на однократном поиске атаки до завершения ответа перемещения. Исправленное ожидание проверено в полном настольном/мобильном сценарии, в том числе с задержкой ответа 500 мс. Новое парное измерение каталога улучшило локальный API для группы из шести; общая UI/production скорость ещё не принята. [Подробности](CI-17-browser-boundary.md).

Полный CI18 прошёл; следующая публикация отправила три образа, но не опубликовала кандидата. Исходная диагностика не раскрывает точную причину этого hosted отказа. В отдельном локальном запуске нативного Linux воспроизведён отказ из-за длины пути временного сокета; исправление прошло обе пары фактических образов локально. Дополнительные 60 измерений реального UI показали смешанный результат batch, поэтому он остаётся OFF. [Подробности и границы доказательств](CI-18-writer-browser-repair.md).

Полный CI19 прошёл. Публикация остановилась при повторном чтении predecessor до браузера; ограниченные GET-повторы и безопасная диагностика проверены локально, включая один восстановленный настоящий транспортный сбой. Новая серия из 160 измерений интерфейса не подтвердила устойчивого выигрыша batch; он остаётся OFF. [Подробности](CI-19-metadata-reader-repair.md).

Полный CI20 и публикация настоящей пары образов с браузерной проверкой прошли. Серверная выкатка остановилась на девятой проверке после восьми успешных; рабочие сервисы не заменялись. Локально воспроизведён и исправлен отказ восстановления полной конфигурации после проверки сжатия. Требуется новый точный CI исправления. Отдельные 160 измерений UI не показали ускорения от сжатия квитанций; уменьшение новых записей БД остаётся самостоятельным результатом. [Подробности и машинная запись](CI-20-writer-policy-repair.md).

CI21 подтвердил все 944 Node-проверки, но выявил преждевременное ожидание API в тесте ленивой загрузки правил. Исправление теста проверено локально с управляемой задержкой импорта; production code неизменен. Частичный CI не принят для выкатки.
