# Устойчивое чтение метаданных GitHub

Первая попытка выкатки `37581756410/1` остановилась в подготовке из-за HTTP 500 GitHub. Задание доставки на сервер было пропущено; ошибка не означала неисправность приложения. Уже существующая повторная попытка продолжает проверку кандидата отдельно от этого изменения.

Общий транспорт чтения теперь используется выбором релиза, проверкой актуального main и сборщиком writer proof. Он выполняет только GET, повторяет временные сетевые ошибки и 500/502/503/504 максимум три раза, ограничивает ожидание квоты десятью секундами и каждый раз получает настоящие свежие метаданные. Ошибки прав и некорректный JSON не принимаются как успех. Запросы изменения, включая dispatch, не повторяются автоматически. Диагностика не содержит токены и тела ответов.

Проверены 89 связанных контрактов, без ошибок и пропусков; проверки секретов и дампов прошли. В проде это исправление пока не установлено. Полный автоматический release gate обязателен перед интеграцией.
