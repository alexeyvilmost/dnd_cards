# Новый пакетный API предметов в браузерной фикстуре

CI `37585930719/1` для A161 завершился ошибкой расширенного набора: сценарий
сохранённой атаки листа проверял отсутствие ошибок браузера и получил HTTP 404.
Публикация и выкатка A161 не начались; на сервере остаётся D229.

Изолированная фикстура обслуживала `/api/cards/runtime/resolve`, но новый
`/api/cards/resolve` попадал в обработчик одиночного `/api/cards/:id`.
Он искал предмет с ID `resolve`. Приложение корректно использовало совместимый
fallback, однако браузер фиксировал ошибку исходного запроса. Исправлен контракт
фикстуры: обе точные пакетные GET-маршруты используют существующую ограниченную
проекцию каталога перед обработчиком одиночного предмета. Код приложения,
fallback, проверки консоли и условия выпуска не менялись.

Новый браузерный тест проверяет два разных предмета: ответ пакета совпадает
с их одиночными проекциями, повторный ID не дублирует строку. Для обоих маршрутов
проверяются пустой/неправильный ID, повторный параметр, предел 128 запросов
до удаления дублей и отказ без частичного ответа при отсутствующем предмете.
Проверки реального API, прав и метаданных остаются отдельными серверными тестами;
браузерная фикстура не заменяет серверную авторитетность.

До исправления локально воспроизведены три ошибки 404 в том же сценарии.
Запуск `test_dc3d34daadf0e5576e87d256`: 16 passed, 2 failed, 0 skipped.
Дополнительная ошибка первого десктопного сценария `ERR_PROXY_CONNECTION_FAILED`
сохранена в исходном отчёте; её причина отдельно не установлена и она не
добавлена в исключения проверки консоли.

После исправления весь production UI-fixture набор прошёл на десктопе и
мобильном экране: **50 passed, 0 failed, 0 skipped, 0 flaky**, 96,95 секунды
Playwright, запуск `test_08f36e31140a2d49619e4385`.
Использована та же неизменяемая сборка UI, созданная перед воспроизведением;
совпадают hashes index и manifest. Оба собственных локальных стека завершены,
ошибок cleanup нет. Дополнительно прошли scoped ESLint, diff whitespace check,
проверки tracked dumps/credentials и source-catalog manifest (440 файлов).

Машинный локальный результат и hashes двух изменённых исходников:
`outputs/testing/display-batch-browser-fixture-fix-20261007.json`.
Исходные требования всех 29 задач не изменялись. Этот результат разрешает новый
CI исправленного коммита, но не подменяет CI, публикацию или принятие выкатки.
