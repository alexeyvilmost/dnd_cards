# CI15 и первая подтверждённая выкатка

Версия `93265633db105f6027ddd94cc4d8952747524fd4` прошла [полный CI](https://github.com/alexeyvilmost/dnd_cards/actions/runs/37386799187), [публикацию трёх образов](https://github.com/alexeyvilmost/dnd_cards/actions/runs/37388524104) и [выкатку](https://github.com/alexeyvilmost/dnd_cards/actions/runs/37389067128). Независимая проверка подтвердила публичные ответы HTTP200, исходники/образы/запуски трёх компонентов, 305 записей миграций и здоровый Sota gateway. Постоянный ключ доступа сохранён. Платный запрос при этой проверке не выполнялся.

CI: 731 Node, 6462 Vitest, 754 обязательных случаев Go, 25 DB/worker, 22 проверки курсора, 12 браузерных сценариев, 48 UI и 8 battle3D. Все части и cleanup успешны; измеренная длительность 883148 мс относится к этому запуску.

Семь отдельных опытов инициализации сохранены. В парном HTTP опыте native SHA ускорил медиану для группы из шести на 14%, но ухудшил p95 на 8%; для группы из двух медиана ухудшилась на 7,5%. Эта гипотеза не включена. CPU-замер отдельно не считается ускорением интерфейса.

По явному решению владельца backups пока хранятся на основном сервере. Внешняя копия отложена; проверка восстановления на отдельной БД, исполняемых правил, истории и свежести остаётся обязательной.

Следующий пакет проверен локально: 174 Windows PASS и пять Linux-only пропусков; 179 Linux PASS без пропусков. Это подготовка следующего исходника, а не его точный CI или выкатка. Новые writers, selective и auto остаются OFF до соответствующих реальных проверок. [Машинная запись](CI-15-healthy-adoption.json).
