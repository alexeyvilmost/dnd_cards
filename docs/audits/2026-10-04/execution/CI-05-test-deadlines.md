# Пятый полный CI и локальные ограничения времени

Полный [CI37261886898](https://github.com/alexeyvilmost/dnd_cards/actions/runs/37261886898) коммита `be8a87f1948f36c2b45f0c4eca8d583b1adb4386` завершился ошибкой только в Vitest. Node: 668/668; сервер: 753 Go с race и 20 worker/DB; основные браузерные сценарии: 12; дополнительные production UI: 48; 3D: 8/8. Остальные расширенные проверки прошли. Подробности Vitest в этом hosted run не сохранены; число прошедших Vitest-тестов ему не приписывается. Публикации образов и выкатки приложения не было.

Отдельный Linux-повтор точного архива этого коммита, 730 выбранных файлов, два Vitest worker и CPU affinity 0–3: 6461/6462 PASS. Единственный сбой — `frontend/src/pages/rulesLabFixture.generated.test.ts:159`; длительность 30530,84 мс при явном лимите 30000 мс. JSON содержит только `STACK_TRACE_ERROR`. Адресный прогон показал три последовательные полные компиляции: суммарно около 8,7, 17,1 и 25,8 секунды. Третья была избыточной: настоящий `generate()` уже выполняет вторую независимую компиляцию и атомарную запись. Тест сравнивает её полные байты с первой сборкой, сохраняет current/stale drift, hashes, чистоту временного каталога и проверяет неизменность checked-in данных до и после всей работы. Лимит 30000 мс сохранён. Исправленный адресный Linux-прогон: 4/4 PASS, затронутый тест 17020 мс. Новый полный повтор ещё идёт. Эти локальные результаты не доказывают, что hosted run упал в том же месте.

Для следующего прогона runner сохраняет только выбранный исходный файл, число неуспешных assertions и доступные координаты того же файла. Названия тестов, значения assertions, сообщения ошибок, DOM и raw JSON остаются приватными. Windows: 56/56 privacy/selector/shard/policy проверок; Linux: 4/4, включая настоящий неуспешный дочерний Vitest.

Отдельно воспроизведён дефект ожидания готовности 3D: при Chrome for Testing154.0.8037.57, `CI=1`, trace off и 2 CPU прежний тест прошёл 6/8. Реальный ответ `boundingBox()` с размерами 1404×758 пришёл за 5431 мс, позже стандартных 5 секунд. Локальное ожидание увеличено до уже используемого для видимости canvas лимита 30 секунд. Критерий `width > 100 && height > 100`, игровые assertions, глобальные лимиты и число retries не менялись. Финальные исходники: Linux 2 CPU 8/8, Linux 4 CPU 8/8, Windows адресно 2/2; везде без retries. Это не объясняет автоматически все три старых сбоя CI37260045226; последнее неизменённое 3D CI уже прошло.

Все старые неуспешные отчёты сохранены. [Машинная запись](CI-05-test-deadlines.json) связывает новые выводы с SHA-256 реальных приватных receipts. Адресные проверки и scans позволяют коммит исправлений; перед публикацией обязателен новый успешный полный CI точного коммита.
