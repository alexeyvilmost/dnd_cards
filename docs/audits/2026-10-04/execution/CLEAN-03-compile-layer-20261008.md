# CLEAN-03: устранение повторных файлов в образе фронтенда

Локально проверено; коммит, настоящий CI и выкатка этого изменения ещё не выполнены. Текущую выкатку 78cdd7d2 изменение не затрагивает.

В Dockerfile один набор DiceBox, логотипа и PWA-иконок попадал в образ дважды: через полный public media layer и через dist после Vite. Новый compile-layer сохраняет только сгенерированные файлы и отличающиеся overrides. Побайтно совпадающие public-файлы предоставляет прежний media layer. Исходные изображения, ссылки, лицензии и история Git сохраняются. WebP остаётся выключен.

Перед измерением fingerprint исходного фронтенда сверён с принятым образом 35a9. Отличия build context — только Dockerfile, его ignore и новый helper. Новый образ собран локально с закреплёнными base images, опубликован и прочитан из собственного loopback registry. Измерение включает проверенные по hash manifest/config/layer/attestation payload, исключает headers/TLS и не обещает скорость холодного Docker pull. Синтетический source commit локального стенда не выдаётся за production commit.

Все 635 файлов /usr/share/nginx/html совпадают по путям и SHA-256 в обоих образах. Windows и Linux: 19/19 адресных тестов, 0 skip. В реальной сборке прошли TypeScript, Vite и оба DiceBox guard. Новый тест автоматически входит в extended manifest. Сравнение точного множества файлов исправило необоснованный порог >1000 в первом проверочном helper; исходный отказ сохранён.

Clone/archive не уменьшаются: оригиналы сохранены. Source context измерен отдельно в [машинном отчёте](CLEAN-03-compile-layer-20261008.json); это не сетевой transfer. Начальная загрузка браузера не меняется, поскольку раздаваемые файлы идентичны. Предыдущие измерения WebP/PWA сохранены в [историческом отчёте](CLEAN-03-media.md).

Ресурсы двух локальных проверок удалены по ownership; production и платные API не затронуты. Следующий шаг — после принятия полной выкатки 78cdd7d2 коммит и настоящий CI → publication → deployment, затем проверка component identities. Для отката достаточно предыдущего frontend image; БД не восстанавливается.
