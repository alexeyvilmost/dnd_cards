# CI22 и подтверждение отказа до замены сервисов

Полный CI22 для `a3e8159c` прошёл: 944 Node, 6462 Vitest, 754 обязательных Go, 25 DB/worker, 48 UI, 8 battle3D и 12 основных браузерных сценариев. Общая обязательная выборка полна, пропусков нет, owned cleanup завершён. Это проверка именно `a3e8159c`, а не следующего исходника.

Публикация остановилась до POST. Обычный selector обнаружил последний фактический failed deploy `37405297914/1`; подтверждённая здоровая версия `93265633` сама по себе не разрешала обойти этот отказ. Повторный read-only аудит сервера подтвердил пять исходных фаз, отказ на writer rehearsal после восьми PASS, отсутствие ready/deployed-release/журнала замены, остановленные временные ресурсы, неизменные пять retained files и здоровый прежний состав.

Добавлена ограниченная проверка одного source-controlled подтверждения. Она сохраняет статус failed у исходного workflow, проверяет его настоящий номер попытки и время завершения, требует подлинного unexpired successful predecessor и его manifest hash. Неизвестный исход, новый непроверенный отказ, rerun, изменённая история или истёкший артефакт блокируют продолжение. На сервере исходные hashes, отсутствие поздних фаз, cleanup, live identities, DB binding и retained bytes перечитываются перед capture и ещё раз под обычным deployment lock. Свежий backup, вся история, девятая проверка и 30-минутная граница остаются обязательными.

Локальные результаты и их точные числа сохранены в машинной записи. Отдельный Linux reader test подтвердил normal Git mode `0644`, защищённые файлы, собственный lock и отказ при появлении поздней фазы. Это unit-проверка с контролируемыми Docker/HTTP observations, а не выкатка или свидетельство запусков приложения в OCI. Реальный selector также проверил настоящую историю GitHub без POST и выбрал прежний genuine successful deployment с ровно одним reviewed refusal.

Независимое измерение ускорения каталога завершено: 176 принятых запусков, 160 измеренных, по 40 каждого варианта для групп 1 и 6. Для шести медиана 771→684 мс (−11,28%), p95 1019,5→972,2 мс; SQL operations 183→58. Для одного медиана 294,5→299,7 мс: выигрыша нет. Семь DB/actual-worker проверок прошли, retry/reload и исходные листы сохранены. Это частный Go overlay с новым RNG каждого UI sample; production и mobile latency не заявляются. Пятистрочная правка подготовлена отдельно, не интегрирована.

Рабочая версия — `93265633`; writers, selective, auto и reconcile OFF. Следующий исходник проходит новый точный полный CI, публикацию и всю серверную репетицию. Backups пока хранятся на основном сервере по решению владельца. [Машинная запись](CI-22-reviewed-followon-recovery.json).
