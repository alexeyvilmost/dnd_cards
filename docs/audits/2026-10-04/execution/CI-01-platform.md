# Первый запуск в GitHub и переносимость стенда

Коммит `ded378c6da5a6a8b998c31515cfefb8d2d7c8863` отправлен в `main` после локальных проверок. [Первый полный Linux CI](https://github.com/alexeyvilmost/dnd_cards/actions/runs/37254785060) завершился неуспешно: PostgreSQL не запустилась в изолированных стендах. Публикация образов и выкатка приложения не выполнялись.

У временной БД был задан TCP-адрес `127.0.0.1`, но сохранялся системный каталог Unix-сокета. В отдельном Linux-контейнере непривилегированный процесс воспроизвёл отказ записи lock-файла в каталог, принадлежащий root. Отключение неиспользуемого Unix-сокета устранило отказ: соединение через loopback с правильным случайным паролем прошло, неверный пароль отклонён. Это контролируемая проверка PostgreSQL 17.11 на Alpine, а не утверждение об исполнении в Ubuntu GitHub. Проверка того же исправленного драйвера на Windows также прошла; стенды остановлены.

В первоначальном публичном отчёте блока Node не было места ошибки. Повтор его 100 файлов на Linux с точными исходниками первого коммита дал 650 успешных тестов и четыре неуспешных: этим четырём в минимальном диагностическом контейнере не хватало `initdb`. Остальные проверки прошли. Такой результат не объявляется полностью успешным повтором CI и не доказывает причину всех исходных ошибок GitHub.

Теперь runner сохраняет только путь выбранного тестового файла, строку и классификацию ошибки из фиксированного набора. Текст ошибок, названия тестов, значения утверждений, SQL, окружение и полный вывод не попадают в публичный отчёт. Пять проверок диагностического обработчика, включая настоящий дочерний Node-процесс с ошибкой и попытки подмены полей, и 14 проверок выбора тестов прошли. Строгость результатов и запрет пропущенных тестов сохранены.

Следующая проверка полного набора в Ubuntu по точному новому коммиту обязательна до публикации. Исторические неуспешные результаты сохраняются; новое исправление не меняет их статус.

Четыре файла, которым в минимальном Linux-контейнере не хватало PostgreSQL, дополнительно выполнены на Windows с исправленным настоящим драйвером: 7/7 тестов прошли, включая полный инвентарь исторических ссылок, экспорт изображений и применение/откат разрешённой очистки индекса. Эта проверка не заменяет предстоящий Ubuntu CI.
