# Исправления, найденные общим расширенным прогоном

Прогон `outputs/testing/final-v3-extended` завершился с ошибками и сохранён как неуспешный. Его отдельные успешные сценарии не являются приёмкой всего набора. Все созданные им стенды остановлены.

- Аудиотест предполагал, что два mock-запроса обязательно пересекутся за 10 мс. При задержке записи intent это неверно даже для исправного пула из двух работников. Тест теперь удерживает первую пару до фактического старта обоих запросов, проверяет число активных работников и освобождает запросы даже при неудаче проверки. Поведение production не менялось.
- Go на Windows дважды завершал успешную discovery/compile-only операцию ошибкой удаления собственного временного `.test.exe`. Runner допускает один новый запуск только при точном сочетании успешных результатов ожидаемых пакетов и единственной такой ошибки в каталоге `TEMP/go-build…`. Первая ошибка и отдельный лог повтора сохраняются; только успешный код завершения новой операции разрешает продолжение. Ошибки реальных тестов, компилятора, неполные результаты и неизвестные ошибки не повторяются и не считаются успехом. Контракты и аудиотест: 40/40 Node PASS; настоящий запуск пяти Go-тестов — 5/5 PASS без повтора тестов.
- Новый пакетный API предметов не объединял одновременные запросы. Два regression-теста воспроизвели дубли пакетного чтения и старого single-item fallback. Исправление использует общий кеш только на время запроса, с ключом текущей сессии и отсортированным набором ID. Порядок каждого вызывающего сохраняется; завершённые приватные ответы не удерживаются, отзыв прав проверяется следующим чтением. После исправления 37/37 тестов чтения и кеша прошли. Браузерный API fixture дополнен фактическим новым endpoint и кодами ошибок; проверки отсутствия лишних запросов и ошибок браузера сохранены.

Повторная проверка двух затронутых browser files прошла на свежей production-сборке: **20/20 PASS**, без пропусков, desktop/mobile Chromium, включая неизменённый строгий запрет одновременных дублей GET. Стенд `test_547e09db3a40b02ba5468462` остановлен; [receipt](PERF-04-bulk-browser-followup.json) связывает результат с точным frontend source hash и UI manifest. Независимая проверка подтвердила, что guards не ослаблены ради fixture.

Повторные полные core/extended наборы после этих исправлений и проверка точного опубликованного коммита учитываются отдельно. Первые успешные core-отчёты остаются историческими снимками, их source hash не заменяется.
