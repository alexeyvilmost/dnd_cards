# Публичный набор для исторических тестов

Подготовлены четыре публичных набора размером 1 370 027 байт: исходные данные до 278/279, сведения для 296 и состав предметов. Все 1605/2374/42 исходные условия проверены по фактическим сохранённым значениям. Личные поля, поддержка, сертификаты и необязательные изображения исключены; ссылки на ресурсы, обязательные для условий 279, сохранены.

Загрузчик сверяет manifest, размеры и хэши сжатых и распакованных данных; отказывает при подмене, неоднозначных идентификаторах, секретах или поддержке. Его девять новых случаев включены в обязательный security-selection набор. Локально прошёл 41 тест без пропусков.

Отдельный полный прогон с этими публичными проекциями выполнил все 303 оригинальные миграции до 307 и точный повтор. Исходные дампы и код сохранились, временные ресурсы остановлены. Сертификаты для прежних revocations взяты из защищённого подлинного архива, не входят в публичный набор и не превращены в новые сертификаты.

Штатный migration-профиль и CI ещё требуют включения адаптера полного прогона. Текущий результат не объявляет TEST-05 завершённой и не является production bootstrap.
