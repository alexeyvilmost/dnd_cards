# PERF-05 — проекция карты и устойчивое отображаемое состояние

04.10.2026, локально. Реализована первая часть: устранение повторного построения статической проекции на hover/camera/выделении. Каноничные исполнение, геометрия и attack preview сохранены. Production FPS/длинные сессии/полный browser-frame benchmark не объявляются проверенными.

## Изменения

- `SoloCombatPage` мемоизирует display state по авторитетному/анимационному состоянию и каталогам портретов. `combatDisplayState` сохраняет исходный объект и токены, пока URL фактически не изменился. Команды используют прежнее авторитетное состояние.
- Из `TacticalBattleMap` механически выделен `projectTacticalMapState`: геометрия, footprints, приоритет живого обитателя, мировые объекты, предметы, области, описания и освещение вычисляются один раз на полную identity состояния, не только boardRevision. Поверхности аур тоже считаются здесь один раз на клетку вместо двух вызовов в каждом render.
- Hover, маршрут, достижимость, выбор цели и выделение остаются отдельным слоем. Новое состояние экипировки, ресурсов, эффектов, света, перемещения, HP, мира, карты или хода консервативно инвалидирует проекцию. Нет кэша по одному action ID или хеширования всего боя на mousemove.
- `previewCombatAttackRoll`, `previewAttackCover`, маршруты, каноничные карточки/диалоги и настройки иконка/строка не заменялись. Held→committed не менялся; повторных бросков нет.

## Baseline и результат

Новый регрессионный тест сначала выполнен на исходном компоненте. Карта24×18, четыре источника света, стена, 30 перемещений указателя и30 смен выделения при неизменном мире:

| Показатель | До | После |
|---|---:|---:|
| Первый расчёт освещения клеток |432|432|
| Повторные illuminationAt на hover |25920|0|
| Повторные поверхности аур на hover |две на клетку/render (исходный код)|0 (spy assertion)|
| React Profiler renders |60|60|
| Суммарное render time, ms |480.63|381.69|
| Среднее render time, ms |8.01|6.36|

Сырые отсчёты: [PERF-05-before.log](PERF-05-before.log), [PERF-05-after-final.log](PERF-05-after-final.log). Наблюдаемое render time уменьшилось примерно20.6%, но это React development/JSDOM, не браузерный кадр и не SLA; параллельная работа/JIT не изолированы. Строгое доказательство — число реальных повторных вызовов. Промежуточные after-логи сохранены: под нагрузкой их wall-time был хуже baseline; улучшение каждого отдельного замера не утверждается.

После перемещения света тест требует ровно432 новых вычисления; отдельно проверены новые tokens, world/resources, удалённые объекты и ambient light. Входной state полностью неизменен после hover. Отдельно проверены identity неизменившихся портретов и обновление двух разных источников изображения.

## Проверки

- TacticalBattleMap.performance, TacticalBattleMap, SoloCombatPage.3d-parity, displayState, creatureCover, movementHazardPreview, projectilePreview:7 файлов,65/65 PASS после первого переноса. Финальный перенос surface projection дополнительно проверен performance-test (PASS).
- Существующая parity suite использует реальные каноничные атаки, разные оружейные профили, боезапас, area/movement, оба renderer, held roll и defensive reaction. Геометрические тесты покрывают разные размеры тел, rays/cover и hazards.
- Новый performance-test намеренно был красным при baseline; расширенный прогон коллеги застал эту промежуточную фазу. Assert не ослаблялся; после реализации targeted run зелёный.
- TypeScript проверен на первом переносе; финальный повтор включает также независимые изменения других агентов. Независимый CLEAN-03 resolver URL фона не относится к этому измерению.

## Ограничения и откат

Остаются production-browser long tasks/FPS на большой 3D-карте, мобильное устройство, сотни ходов и сложные смешанные пассивы. Preview cache между разными мирами не добавлен: ему нужно отдельное доказательство инвалидации/равенства с исполнителем. Откат — убрать memo-слой, сохранив тот же чистый проектор. Сохранённые состояния и артефакты не менялись.
