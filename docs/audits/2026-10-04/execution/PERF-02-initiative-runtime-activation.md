# Включение серверной подготовки инициативы

В версионную конфигурацию следующего выпуска добавлен один параметр: серверная подготовка инициативы включена. Она использует общий каноничный сборщик и выдаёт варианты действий без изменения БД; initialize по-прежнему заново проверяет доступность и стоимость. Повторная полная сборка участника в браузере для этого предложения больше не нужна.

Настоящий Docker Compose разобрал прежнюю и новую конфигурации на локальных служебных входах. После разрешения параметров отличается только этот флаг; остальные настройки и сервисы совпадают. Прошли 27 существующих контрактных проверок сохранённого запуска, неизменяемой конфигурации, отката и привязки runtime profile без пропусков. Свежая проверка текущего приложения отдельно подтверждает четыре браузерных сценария, действия с разной ценой/костями, группы 1/2/6, превью, расход ровно один раз и сохранность после reload.

Изменение пока локальное. В текущую выкатку Main95546ec3 оно не включено. Следующий выпуск должен пройти обычную проверку точного коммита и свежей копии БД, затем фактическая конфигурация ON проверяется на сервере. При application rollback используется сохранённая конфигурация предыдущего выпуска с OFF; рабочую БД не восстанавливают из старой копии. Реальный откат нового выпуска этой локальной проверкой не подтверждён. Нового измерения скорости прода нет; прежний компромисс медианы и хвоста остаётся в отдельном отчёте.
