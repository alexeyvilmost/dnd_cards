# Восьмой CI и воспроизводимый сбой подготовки каталога

[CI 37269128668](https://github.com/alexeyvilmost/dnd_cards/actions/runs/37269128668) проверил точный коммит `0125f4c8e7cb8abf1a73028503e31f2fe8a518e7`. Прошли 681 Node, 753 обязательных Go с race, 20 worker/DB, 12 основных браузерных сценариев, 48 production UI, все 8 проверок 3D и остальные расширенные gates. Cleanup прошёл. Общий результат FAILED: Vitest сохранил suite-level ошибку каталога без failed assertions и текста причины. Число прошедших Vitest по этой записи не восстанавливается; причина именно hosted-сбоя остаётся неизвестной.

На неизменённом исходном коммите при 1,5 CPU, 4 GiB и двух workers совместный Linux запуск каталога и генератора Rules Lab воспроизвёл timeout beforeAll 30 секунд: 4 PASS, 15 SKIPPED. Единственное изменение явного лимита подготовки на 60 секунд, уже принятого общей конфигурацией hooks, дало 19/19 PASS. Лимит каждой проверки остаётся 30 секунд. Каталог, все assertions, генераторы и исторические артефакты не изменены. Собственные контейнеры остановлены. Это доказанный локальный риск подготовки, а не восстановленная причина исходного CI.

Вложенная ошибка beforeAll теряется в JSON-отчёте Vitest. Следующая проверка сохранит фиксированную категорию и координаты через публичный reporter API; приватные сообщения, имена и значения не публикуются. Дополнительно устраняется пограничная ошибка проверки возраста резервной копии: текущий момент измеряется после проверки её байтов. Лимит 30 минут и исходное время создания копии сохраняются.

[Машинная запись](CI-08-catalog-setup.json) связывает отчёты и локальный RED→GREEN хешами. Образы ещё не опубликованы, приложение на TimeWeb остаётся на `4549fb3c`. Для выкатки требуется новый полный успешный CI.

Минимальные исправления интегрированы в следующий кандидат. Адресная совместная проверка Windows: **60/60 PASS, 0 SKIP**; новый reporter отдельно Linux: **6/6 PASS**. Reporter используется только для диагностики неуспешного запуска, не заменяет exit code, JSON verifier, counts или обязательное покрытие. Проверки reporter и возраста backup включены в основной обязательный набор. Полный новый CI ещё предстоит.
