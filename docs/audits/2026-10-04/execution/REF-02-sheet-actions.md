# REF-02 — модель и отображение действий листа

Из `SheetActionsPanel` выделены `sheet-actions/actionModel.ts`, `actionAvailability.ts`
и `SheetActionList.tsx`. Панель сокращена с 3565 до 3153 строк: загрузка и выполнение
команд остаются в ней, чистые селекторы и каноничное отображение имеют отдельные границы.
Общий размер репозитория этим переносом не уменьшен: интерфейсы и проверки добавлены.

Селектор доступности перенесён без смены порядка проверок. Сверены исходный и перенесённый
тексты тела функции после нормализации пробелов. Он по-прежнему вызывает существующие
проверки стоимости, экипировки, права на канонический combat session и pending retry.
Он не бросает кубики, не расходует ресурсы и не заменяет повторную проверку при исполнении.
Для прежних потребителей сохранены совместимые re-exports из панели.

`SheetActionList` использует существующие `SheetActionGroups` и `SheetActionLine`.
Через прежнюю панель его используют обычный лист, лист в столкновении и мобильный просмотр.
Сохранены фильтр реакций, каталог неподготовленных заклинаний, конкретная ошибка загрузки,
настройка icon/row, каноничные превью, режим просмотра недоступного действия и обработчики
основной команды. Новый второй движок доступности не создан.

Адресный набор: **46/46 PASS, 0 skips** — новая проверка двух разных деклараций с общей
стоимостью, неизменность runtime после просмотра, строки/иконки, фокус/каноничное превью,
отсутствие активации недоступной строки, мобильный inspect без команды; также прежние
upcast, camp, surface lock, target facts, atomic events и presentation tests.
Полный TypeScript и общий fresh core/extended фиксируются отдельно после всех изменений.

этого механического переноса не заявляется; профиль общего REF-02 и route graph проверяются
вместе с завершённым срезом SoloCombatPage.
