# CLEAN-03 — медиа, доставка и PWA

Медиа-инвентаризация, офлайн-оболочка и включённая локальная сборка с lossless-вариантами проверены. Приняты 17 вариантов с точным совпадением пикселей в Chromium; 76 файлов с проблемной полупрозрачностью оставлены в исходном формате. Git cleanup/переписывание истории не выполнялись. Docker image/pull bytes ожидают среды с Docker daemon.

## Проверенная оболочка

Vite создаёт build manifest. PWA берёт точное замыкание статических imports главного entry, его CSS и русские/латинские шрифты. Ленивые route chunks с именем `index-*` больше не попадают в установку только из-за имени. Отсутствующий обязательный static import приводит к ошибке сборки. Новая offline policy не кеширует `/api` и допускает runtime cache только для своего origin.

Новая сборка: **19 precache entries, 860.35 KiB** вместо 2101049 bytes после PERF-04 (примерно −58%). Это install bytes, не размер всего dist и не измерение скорости открытия страницы. Текущий dist 169174309 bytes включает сохранённые оригиналы и ленивые chunks.

Два build-contract теста PASS. Настоящий Chromium/Service Worker: [CLEAN-03-pwa.json](CLEAN-03-pwa.json), owned test_b743a453dad7e62c2976bbe3, точный snapshot manifest в отчёте. Проверены отсутствие ленивых страниц в precache, отсутствие API в caches, успешная перезагрузка ранее открытой страницы входа без сети и ноль page errors. Приёмка не обещает игровые команды офлайн. Gate включён в extended.

Nginx теперь даёт `immutable` только content-hashed filenames; стабильные public media URLs перепроверяются. Существующие URL сохранены. Nginx runtime проверка остаётся частью Docker gate; локальный браузерный gate использует native test server и не считается проверкой Nginx-конфига.

Описание используемых механизмов: [Vite build manifest](https://vite.dev/guide/backend-integration.html), [Vite PWA precache](https://vite-pwa-org.netlify.app/guide/service-worker-precache). Исходный media layer отделён от app compilation в REL-02. Подробная инвентаризация дополняется в CLEAN-03-media.md.

## Реальное приложение с вариантами

Подробные доказательства находятся в [CLEAN-03-real-app.md](CLEAN-03-real-app.md): 11 основных пользовательских сценариев, 48 desktop/mobile и 8 сценариев 3D прошли без пропусков и повторов. PDF и JSON действительно сформированы и сверены с сохранённым документом. В трёх естественно созданных боях проверены запрос варианта карты и fallback к оригиналу, размеры и декодирование; сохранённые игровые URL не изменены. Визуальная проверка выполнена по скриншотам.

Передача выбранных 17 изображений сокращается с 42,82 до 29,45 МБ, но включённая сборка становится больше примерно на 29,4 МБ, поскольку сохраняет оригиналы. Уменьшение размера Git не заявляется. Media-флаг выключен по умолчанию; OCI schema v1 явно запрещает его включение без будущего контракта входных файлов. Печатный экспорт листа проверен; автоматическое переключение TacticalMap на оригинал при произвольной печати страницы браузером не реализовано.
