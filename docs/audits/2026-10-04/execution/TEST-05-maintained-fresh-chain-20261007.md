# Полный поддерживаемый исторический профиль

Локально исполнены все **303 исходные зарегистрированные миграции** от legacy bootstrap. Повторный запуск сохранил все **98 таблиц / 24592 строки**, включая одну строку владения тестовой БД. Три исходных отзыва 102/103/119 сохранили подлинные preimage; четыре ручных статуса не повышены и механики не заблокированы. PostgreSQL остановлен без ошибок. Исходники и исходные guards не изменялись во время прогона.

16 прежних диагностических адаптеров перенесены в поддерживаемую папку. Данные берутся из публичных catalog fixtures, закреплённых Git blobs и отдельной капсулы трёх подлинных архивных отзывов. Полный приватный dump больше не нужен. Входы фаз задаются явно; этот тест не заявляет возможность обычного production bootstrap без таких входов. Журнал миграций не засевается.

Первый прогон строго отказал на 118: native PostgreSQL с локалью C не приводил кириллицу к нижнему регистру. Сравнение C и built-in C.UTF-8 на русском и греческом подтвердило причину; настройка изменена только для явно выбранного тестового профиля. Оригинальные миграции не исправлялись под тест.

Профиль включён обязательным gate historical-fresh-chain в extended; проверки чтения архивных входов включены в core. 68 адресных тестов, включая проверку обязательного маршрута, прошли без skip. Локальный source checkout содержал новый незакоммиченный профиль; точные hashes всех входов сохранены в [машинной записи](TEST-05-maintained-fresh-chain-20261007.json).

Общий gate через действительный shared stack также прошёл все 303 миграции; оба принадлежащих тесту стенда остановлены. После финальной нормализации исходников отдельный полный прогон повторён и прошёл на точных текущих байтах. Hosted CI нового профиля ещё не запускался; локальный результат не является его доказательством. Production SQL и платные вызовы не выполнялись.
