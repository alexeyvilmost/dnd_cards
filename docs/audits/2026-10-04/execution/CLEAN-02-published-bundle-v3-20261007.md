# CLEAN-02: граф локального доказательства с опубликованным исполнителем

Формат 3 связывает ранее полученный отчёт настоящих OCI readers с точной парой
manifest и backend-исполнителем: image digest, baked source, input fingerprint,
receipt hash и повтор с нулём новых применений. Source backend сравнивается
с компонентом manifest, поскольку mixed release вправе переиспользовать backend
от предыдущего коммита. Source всей композиции не заменяет provenance backend.
Локальная diagnostic binary/overlay, неизвестные поля и другой source/digest
отклоняются. Схема candidate должна совпадать с настоящим набором миграций
снимка. Будущая 307 требует нового снимка и нового доказательства.

Прежние форматы 1 и 2 сохранены, локальная expansion 301 не может выдаваться
за опубликованную пару формата 3. Profile остаётся строго local-owned;
production-ready, production executor и разрешение DDL не добавлены.

Прошли **58 тестов графа и 198 тестов всех retirement-контрактов**, без ошибок
и пропусков. Отрицательные случаи включают native overlay, подмену source
компонента source всей композиции, другой fingerprint/digest, новый ordinary
schema без снимка, повторное применение и неизвестные поля.

Настоящий граф предыдущей пары `05085d44` → `d2295bf1` проверен на сохранённых
файлах: полный дамп capture `37581756410/2`, реальный приватный архив с доказанным
восстановлением и опубликованные readers 11/11. Исходные manifests и отчёты
не переписаны. Связаны 306 прежних миграций, 93 retained fingerprints
(92 производственные таблицы и собственный marker локального стенда).
SQL подготовлен с хешем настоящего reader report; **не исполнялся** в этом шаге.

Ограничения сохраняются: исходный reader report хранит summary исполнителя,
а полные command metadata/receipt bytes здесь не восстановлены и не выданы
за новое исполнение. Browser acceptance актуальной пары, свежий post307
снимок, доказательства и production host/controller остаются отдельной работой.
БД сервера не менялась; платных запросов нет. Исторический граф не разрешает
удаление на текущем проде или другой паре версий.
