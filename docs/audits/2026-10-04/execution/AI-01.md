# AI-01 — безопасная диагностика генерации

Локально реализовано 04.10.2026. Реальный production 403 ещё не исследован: сеть TimeWeb, ключи и платный API не использовались.

## Изменения

- Введён единый JSON-контракт ошибок: источник application/provider/network, безопасный code, request_id, разрешённые provider code/type, HTTP status, content type и provider request ID. Тела ответов, промпты, ключи, URL и base64 не попадают в диагностический ответ и новые журналы генерации.
- Локальный запрет редактирования контента имеет code `content_admin_required`. Provider 401/403 возвращаются как upstream 502 и не разлогинивают пользователя. Региональный отказ определяется по точному коду, не по одному статусу 403.
- Отказ модели/прав, неверные учётные данные, лимиты, HTML от прокси, timeout/cancel и неопределённый сетевой результат различаются. UI не показывает произвольное тело upstream.
- Удалён автоматический повтор платного POST после EOF/timeout: запрос мог быть уже принят. Отсутствующий клиент обрабатывается без panic. Legacy endpoint перестал сохранять placeholder после отказа и возвращать ложный success.
- Добавлен `docs/image-generation-operations.md` с диагностикой и границами допустимого сетевого решения; актуальные официальные источники проверены при аудите. VPN не объявлен доказанным исправлением неизвестного 403.
