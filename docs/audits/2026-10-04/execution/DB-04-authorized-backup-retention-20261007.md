# Разрешённая очистка резервных копий TimeWeb

Удалены 29 устаревших дампов, освобождено 25,84 ГБ файловой системы. После очистки свободное место выросло с 4,04 до 29,88 ГБ. На сервере оставлены две полные копии; новая копия для текущей попытки выкатки заменила предыдущую после проверки 45 файлов по размеру и SHA-256. Три старых оригинала общим объёмом 2,26 ГБ сохранены на ПК с повторной сверкой SHA-256 и доступом только текущему пользователю Windows.

Рабочая БД не менялась; это освобождение файлов дампов, а не логических таблиц PostgreSQL. Размер повторно используемого места внутри PostgreSQL от этой операции равен нулю. История, receipts, artifacts, служебные доказательства прежних прогонов и действующая проверка кандидата сохранены. Общий TTL и расписание очистки не добавлены. Удаление разрешено отдельным явным запросом владельца.
