# DB-03: текущий код и конфигурация, 100 пар

На D229 выполнены 100 согласованных измеряемых пар OFF/ON и 5 прогревочных пар. Обе руки восстановлены из одного owned snapshot, используют одинаковые binary/CJS и IDs/payloads/revisions команд; порядок чередуется. Кеш подготовки и prefetch выключены, initiative/equipment intent включены. 420 commits, 420 exact retries и 210 reload/source checks прошли; три стенда stopped, источники неизменны, платных запросов и изменений продовой БД нет.

| Метрика | OFF | ON |
| --- | ---: | ---: |
| Initialize median / p95, мс | 94.85 / 120.46 | 92.66 / 120.41 |
| Continue median / p95, мс | 79.02 / 96.60 | 80.60 / 91.85 |
| Runs + catalogs relation bytes | 11517952 | 7045120 |
| Catalog references / immutable rows | 0 / 0 | 105 / 1 |

Физическое уменьшение локальных отношений: 4472832 байт (38.83%). Initialize p95 практически одинаков; bootstrap интервал ON/OFF [0.9113; 1.0329] допускает регрессию до 3,29%. Continue p95 ниже, но его медиана и среднее слегка выше. Поэтому уверенное отсутствие регрессии и ускорение production не заявлены. DB_FROZEN_CATALOGS остаётся выключенным до проверки целевого хоста.

Предыдущие отрицательные серии не переписаны: там были другой backend/artifact и включённый preparation cache. Новый опыт меняет следующие действия, но не является causal-доказательством одной правки. Это native Windows, 1 canonical line fighter на забег; background нагрузка не исключена, игровая entropy настоящая и независимая. Quantile совпадает с историческим paired100 driver (ceil(p*n)-1); его нельзя смешивать с линейным p95 браузерных equipment-отчётов.

Полные исходные приватные диагностические отчёты сохранены в outputs/testing/db03-current100-20261007, безопасные метрики и SHA — в соседнем JSON.
