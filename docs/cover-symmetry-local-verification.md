# Укрытие: локальное исправление 16.09.2026

## Подтверждённая причина

Прочитан локальный забег `2f4e861d-5467-4541-80bf-1df63ac2e7f9` из БД `shop_review_249_20260915`.
Его журнал содержит несколько встреч; расхождение воспроизведено в склепе:
низкий саркофаг `(7,5)`, размер `2×1`, половинное укрытие;
лучница `(8,11)`, гоблин `(8,0)`.

Геометрия возвращает `half` в обоих направлениях. Ошибка находилась в исполнении:
каноническая атака оружием добавляла +2 к КД, а обычная атака из каталога
(в том числе статблок монстра) не добавляла этот бонус ни в прямом пути,
ни в пути с реакцией цели. Поэтому гоблин защищался с КД 17, а лучница — с КД 15.

## Изменения

- Каталожные атаки используют ту же проекцию укрытия, что оружейные, включая окно реакции.
- При восстановлении реакции сохраняется обстоятельственный бонус исходного броска;
  отказ не меняет КД, выбранная защита добавляет только своё изменение.
- Превью защитной реакции также сохраняет исходную КД броска с укрытием.
- Проекция укрытия без явно заданной базовой КД больше не удваивает временные эффекты КД.
- Геометрия, старые броски, HP персонажа и сохранения пользователя не переписаны.
