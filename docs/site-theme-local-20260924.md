# Единое оформление сайта — локальная проверка 24.09.2026

## Границы изменения

- Общая тёмно-зелёная палитра с золотыми акцентами, заголовками и едиными поверхностями/полями/кнопками из `frontend/src/SiteTheme.css`.
- Библиотека и монстры используют общий каталог разделов, боковое меню, поиск и иллюстрированный заголовок. Сворачивание меню анимировано, сохраняется между переходами; учитывается reduced motion. Мобильное меню компактно, фильтры оформлены тёмной панелью.
- Добавлены гостевые входные страницы персонажей и забега; обновлены формы входа/регистрации. Настроенные сценарии авторизации и возврата сохранены. Google/Yandex остаются недоступными, если провайдеры не настроены на сервере.
- Обновлено оформление кузни, списка персонажей, интерактивных листов, настроек, страниц забега и служебных страниц/конструкторов. Изменения косметические, каноничные карточки и механики не заменялись.
- **Бумажный лист исключён из обновления**, включая прежнюю светлую рамку страницы и навигацию на `/paper-sheet` и `/paper-sheet/:id`. Интерактивная светлая тема тоже не принудительно заменяется тёмной.
- Для 13 вкладок созданы отдельные иллюстрации через встроенный imagegen. Ассеты: `frontend/public/images/library/*.jpg`, 1600 px, примерно 122–171 KB каждый. Полные промпты и пути: [library-banner-prompts-20260924.md](library-banner-prompts-20260924.md).
