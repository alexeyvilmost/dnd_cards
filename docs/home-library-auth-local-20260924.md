# Главная, библиотека и вход — локальная проверка 24.09.2026

Изменения не выкатывались, commit и push не выполнялись. Локальный адрес: http://localhost:3001/.

## Что изменено

- `/` — новая иллюстрированная главная с четырьмя направлениями; `/library` — прежняя библиотека. Старые ссылки вида `/?type=spells`, `/?card=…` и с фильтрами сохраняют назначение.
- Из верхнего меню убраны бои, магазин, генерация, документация и инициатива. Монстры доступны из библиотеки. Боковая навигация расширена, на узком экране переносится без горизонтального переполнения.
- Источники: **242 Player's Handbook / 640 Bag Of Holding**, удалённые карточки не меняются. Цена не является критерием происхождения. Подробный реестр: [аудит 262](item-source-classification-262.md).
- Фильтрация доступности предметов работает на сервере, в том числе при прямом запросе скрытой карточки. Для игроков: PH; обычные/необычные/редкие BOH; более высокие известные редкости BOH с устойчивым тегом `Available for Players`.
- Можно выбрать несколько редкостей. Администратор может включить выбор карточек и назначить или снять общий тег атомарно.
- `/paper-sheet` у гостя показывает объяснение, вход и явное создание анонимного листа. У аккаунта — личный список. Документы хранятся на сервере отдельно от игровых персонажей.
- Анонимная ссылка является правом чтения **и редактирования**. Это явно объясняется до создания и в листе. У личного документа право имеет только владелец; чужой запрос получает 404. Перечисления анонимных документов нет.
- Сохранение листа учитывает версию документа: конфликт другой вкладки не затирает изменения, предлагается экспорт JSON. Старый локальный лист можно перенести отдельной копией.
- Вход/регистрация Google и Яндекс реализованы одной кнопкой для каждого провайдера, с PKCE, одноразовым состоянием и обменом кода на сервере. **Настоящие провайдеры пока отключены: ключи приложений отсутствуют.** Конфигурация и ограничения описаны в [OAuth README](../backend/oauth_README.md). Ключи Yandex Storage не подходят для Яндекс ID.
