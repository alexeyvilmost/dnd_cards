# Бумажный лист персонажа: локальная версия

## Открытие и границы

Адрес: [http://127.0.0.1:3000/paper-sheet](http://127.0.0.1:3000/paper-sheet). В верхнем меню добавлен «Бумажный лист»; ссылка остаётся доступной и при свёрнутом основном меню. Адрес с завершающим `/` также поддерживается.

Это самостоятельный редактируемый документ. Авторизация и работающий backend для редактирования самого листа не нужны; маршрут не запускает загрузку сертифицированных правил. Выбор предметов и заклинаний, их превью и просмотр карточек используют API библиотеки. Поля, отметки и локальные счётчики не исполняют боевые команды и не меняют сертифицированное состояние персонажа.

Из каталога `frontend` запускать локально:

```powershell
$env:VITE_API_URL = 'http://127.0.0.1:8080'
$env:DEV_API_PROXY_TARGET = 'http://127.0.0.1:8080'
npm run dev -- --host 127.0.0.1 --port 3000 --strictPort
```

Если `npm` отсутствует в PATH при уже установленных зависимостях, последнюю строку заменяет `node node_modules/vite/bin/vite.js --config vite.config.ts --host 127.0.0.1 --port 3000 --strictPort`. Публикация не выполнялась.

Для проверки реальных библиотечных данных запущен [локальный каталог только на чтение](paper-catalog-readonly-local.md): он использует каноничные обработчики с существующей локальной БД, не запускает миграции и слушает только `127.0.0.1:8080`. Проверенное содержимое локального снимка: 882 предмета, 394 заклинания и 18 тегов.

## Состав листа

Четыре страницы можно смотреть вместе или по отдельности:

- Основная: сведения о персонаже, характеристики, владения, спасброски, навыки, КД, хиты, оружие и текстовые разделы.
- История: портрет, союзники, цели, дополнительные способности и сокровища.
- Заметки: шесть самостоятельных текстовых разделов.
- Заклинания: заклинательная характеристика, производные значения, ячейки и таблица заклинаний; внешность, предыстория, снаряжение и монеты.

Поддержаны редактирование полей и заголовков текстовых разделов, формулы, владение/компетентность, отметки, добавление строк, портрет, масштаб, сетка и размер текста. Заметки содержат обычный текст с полужирным/курсивным/зачёркнутым оформлением, встроенные формулы и локальные счётчики ресурсов. Есть загрузка/скачивание JSON, создание пустого листа и печать всех четырёх страниц.

Визуальные ориентиры — четыре пользовательских снимка и классический лист [Long Story Short](https://longstoryshort.app/), изученный в браузере в доступной пользовательской сессии. Основа каждой страницы — `880 × 1272 px`, сохраняющая пропорции при масштабировании. Рамки, сетка и расположение блоков воспроизведены по образцу; полная попиксельная идентичность и весь функционал исходного сайта не заявляются. Подпись Armor Class приведена к принятой в проекте форме «КД».

Open Sans 400/600/700 для латиницы и кириллицы размещён локально в `frontend/public/fonts/open-sans`; источник — `@fontsource/open-sans` 5.3.0. Лицензия OFL 1.1 и сведения об источнике находятся рядом со шрифтами. Семейство CSS — `Paper Open Sans`, внешние сервисы шрифтов не требуются.

## Редактирование заметок

Нажатие на текст заметки включает ввод в выбранной строке прямо на листе; остальные строки сохраняют оформление. Карандаш также включает редактирование внутри блока. Поле ввода сохраняет шрифт, межстрочный интервал и отступы строки. Изменения сохраняются во время набора. Кнопка «Готово», Escape или переход к другому полю завершают редактирование с сохранением изменений; строка снова показывает оформленный текст, результаты формул и библиотечные ссылки.

Панель инструментов появляется поверх листа под активной строкой и не сдвигает текст или границы блока. Она поддерживает полужирное, курсивное и зачёркнутое оформление, список, вставку формулы, ресурса и ссылки из библиотеки. В небольшом блоке панель может перекрывать область ниже него. При выборе сущности из библиотеки запоминаются курсор и выделение; после выбора или закрытия окна курсор возвращается в заметку. При печати отображается оформленный текст активной строки; поле ввода и панель инструментов скрываются.

## Предметы и заклинания из библиотеки

Значок книги в заголовке текстового раздела добавляет ссылку в конец заметки, а во время редактирования — на место курсора или выделения. Так же работает кнопка «Из библиотеки» в редакторе. В строках оружия, подготовленных заклинаний и настройки на предметы значок книги появляется при наведении/фокусе; на сенсорном экране он виден постоянно. Окно поддерживает предметы и заклинания, поиск по названию, страницы результатов, повтор запроса после ошибки и управление клавиатурой.

Название показано жирным чёрным текстом на прозрачном фоне. Наведение использует общие `HoverCard` и `EntityRefPreview`; нажатие и клавиатурная активация открывают каноничные окна через `EntityDetailProvider` в режиме просмотра. Ссылка не включает редактирование заметки. Окно выбора библиотеки открывается отдельно; после выбора ввод продолжается в блоке заметки на листе.

Ссылка сохраняется в строках документа в общем формате сайта `[[Название|card:UUID]]` или `[[Название|spell:UUID]]`. Название — сохранённая подпись; превью и карточка загружают актуальную сущность по устойчивому ID. Импорт/экспорт JSON и перезагрузка сохраняют эти ссылки. Удалённая или недоступная карточка не стирает название на листе. Значок разорванной ссылки в табличной строке возвращает обычное редактируемое название; в заметке ссылку можно удалить вместе с текстом.

Ссылки пока не добавляют игровую механику в лист: числовые поля, ресурсы и характеристики остаются под управлением пользователя. Внешний фон страницы белый, тень вокруг бумаги убрана.

## Данные и формулы

Модель `PaperSheetDocument` в `frontend/src/paper-sheet/model.ts` имеет `version: 1` и сохраняет исходные строки полей, отметки, уровни владения, тексты/размеры разделов, настройки, количества строк и портрет. Сохранение — один документ в `localStorage`, ключ `bagofholding.paper-sheet.v1`. Изменения переживают перезагрузку. Ошибки чтения или записи показываются явно; нечитаемые сохранённые данные не заменяются автоматически. Импорт сначала проверяется, замена текущего листа требует подтверждения.

Арифметика использует существующий `engine/formula`; модификаторы характеристик, бонус владения и связи навыков переиспользуют `character/rules/foundation`. Грузоподъёмность после выбора размера переиспользует `carryingCapacity` из `character/runtime`. Сохраняется исходная формула, а не только вычисленный результат. При фокусе поле показывает редактируемый источник, после выхода — результат. Пустое производное поле возвращает автоматический расчёт.

| Запись | Значение |
| --- | --- |
| `=10 + [DEX]` | КД с модификатором Ловкости |
| `=8 + [PROF] + [WIS]` | Числовая формула со владением и Мудростью |
| `[STR]`, `[DEX]`, `[CON]`, `[INT]`, `[WIS]`, `[CHA]` | Модификаторы характеристик |
| `str` или `[STR_SCORE]` | Значение Силы |
| `[LVL]`, `[PROF]`, `[skill.perception]` | Уровень, бонус владения, значение навыка |
| `{{8 + [PROF] + [WIS]}}` | Формула внутри заметки |

Доступны `+`, `-`, `*`, `/`, скобки, `min`, `max`, `floor`, `ceil`. Циклы, неизвестные ссылки, деление на ноль и слишком сложные выражения дают локальную ошибку без стирания ввода. Броски костей и выполнение JavaScript не поддерживаются.

## Проверка

Локально прошли адресные тесты модели, элементов листа, библиотечных ссылок и каноничных окон в режиме просмотра: расчёты на разных исходных данных, зависимости/ошибки формул, редактирование, форматирование, счётчики, сохранение/перезагрузка, повреждённое хранилище, переполнение хранилища, подтверждение импорта, проверка переполнения перед печатью и отсутствие действий изменения в окнах просмотра. Проверены оба режима превью предметов из настроек сайта. В окне выбора превью не закрепляется, чтобы вложенные ссылки не открывали другое окно под ним; на самом листе штатное закрепление сохраняется.

Прошли TypeScript, адресная проверка ESLint и полная производственная сборка: Vite, PWA и проверки семи DiceBox-файлов до и после сборки. Vite предупредил о крупных общих JS-частях приложения свыше 500 КБ.

В браузере проверены четыре страницы, редактирование и пересчёт: КД `13`, инициатива `+3`, бонус владения `+3`, пассивное Восприятие `15`. Выполнена визуальная сверка с образцами.

После перехода на ввод в самом поле проверены большой блок «Умения и способности» и компактная «Внешность»: текст вводится без диалога на прозрачном фоне поверх сетки, переносы строк сохраняются, переход между заметками и Escape завершают ввод. Форматирование, формула, ресурс и предмет из реального каталога сохранились после перезагрузки; при возвращении из библиотеки фокус и курсор восстановились. Автотесты дополнительно проверяют сохранение до завершения ввода, отмену выбора библиотеки, выделение при вставке и отсутствие скачка курсора при замене формулы идентичной. Печатные стили скрывают панель и поле ввода, оставляя оформленное содержимое заметки.

С реальным локальным каталогом в браузере проверены добавление предмета в строку оружия, заклинания в заметку и строку подготовленных заклинаний; общее hover-превью и каноничные окна предмета/заклинания; открытие через Enter; сохранение ссылок после перезагрузки и снятие связи с карточкой. Для названий подтверждён вес шрифта `700`; бумага и окружающая область имеют одинаковый белый фон. Созданные при этой проверке пробные записи затем очищены. Отдельно проверены сообщение об ошибке каталога и повтор запроса.

У локального API подтверждены `transaction_read_only=on`, `default_transaction_read_only=on` и `can_manage=false`; изменяющий HTTP-запрос возвращает 405. Полный backend, миграции и обращения API к внешним сервисам для этой проверки не использовались. Готовый PDF не экспортировался.

Повтор адресных проверок из `frontend`:

```powershell
npm test -- src/paper-sheet src/components/EntityDetailReadOnly.test.tsx src/components/EntityRefPreview.test.tsx
npm run build
```

Эквивалент сборки без `npm`: последовательно `node scripts/check-dice-box-assets.mjs`, `node node_modules/typescript/bin/tsc`, `node node_modules/vite/bin/vite.js build --config vite.config.ts`, `node scripts/check-dice-box-assets.mjs --dist`. При ошибке предыдущего шага следующий не запускать. Для локальной проверки использовать указанные выше переменные окружения.

## Ограничения текущего этапа

- JSON-импорт принимает собственную версию документа Bag of Holding. Нативный экспорт Long Story Short не импортируется.
- Хранилище локальное, привязано к браузеру и адресу сайта; синхронизации между устройствами/аккаунтами и списка нескольких листов пока нет. Перенос и резервная копия выполняются через JSON.
- Для поиска и загрузки библиотечных карточек нужен API каталога; при его недоступности сам лист остаётся редактируемым, а существующие подписи ссылок сохраняются. Поднятый локальный каталог обслуживает только чтение: изменение библиотечных сущностей и остальные функции полного backend в нём недоступны.
- Названия, заклинания, предметы и ресурсы здесь являются содержимым документа; выбор названия не подключает игровые механики. Текстовые разделы не являются полноценным HTML-редактором.
- Разметка содержит четыре фиксированные страницы. Перед печатью переполненные заметки/таблицы перечисляются в отдельном окне: можно исправить заполнение или явно напечатать видимую часть. Продолжения на дополнительных страницах не создаются. Системное окно печати/PDF зависит от браузера; готовый PDF в этой проверке не экспортировался.
