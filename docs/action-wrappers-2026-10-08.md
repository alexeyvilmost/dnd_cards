# Очистка выдач действий и кузницы

Локальный сервис: http://localhost:3011/character-forge. Изменения и миграция применены только в изолированной БД `combat_repairs` на 127.0.0.1:5435; прод и соседняя рабочая копия не изменялись.

## Интерфейс

- Квадратные карточки используют общий `HoverCard`, портирующий каноничные превью в `document.body`; превью больше не оказывается под карточками с transform/анимацией. Превью доступно также с клавиатуры и для недоступных вариантов.
- «Изменить» очищает выбранный вид/подвид/класс/подкласс и зависимые выборы. При удалении основного источника сбрасываются его дочерние источники. Левая панель и правое резюме учитывают текущий черновик, даже если асинхронная сборка или отложенное резюме ещё содержат старую сущность. Отмена последнего выбора сохраняется в локальном черновике, чтобы прежняя сущность не возвращалась после перезагрузки; нетронутый черновик, ожидающий восстановления при входе, не затирается.
- Таблица развития скрывает пустые строки и целиком пустые содержательные столбцы после применения переключателя технических выдач. Строки с непустыми ресурсами сохраняются.

## Миграция данных

`scripts/content/action-wrappers-20261008.json` — рассмотренный план с исходными и новыми значениями. `scripts/content/flatten-action-wrappers.mjs` проверяет исходные значения; запись требует отдельного `--apply`. Скрипт не запускается при старте сервиса автоматически.

Пример запуска после резервного копирования, с явной приватной `DATABASE_URL` и `PSQL_BIN` при необходимости:

```
node scripts/content/flatten-action-wrappers.mjs scripts/content/action-wrappers-20261008.json
node scripts/content/flatten-action-wrappers.mjs scripts/content/action-wrappers-20261008.json --apply --archive /protected/catalog/flatten.json --source-commit <exact-40-character-commit> --backup-id <protected-fresh-backup-id>
```

Удалены из живого каталога 35 прозрачных пассивных эффектов, выдававших только действия; обновлены 25 видов/классов и подвидов/подклассов. Выдачи перенесены в `related_actions` или `level_progression.actions`, с прежними уровнями получения. Дополнительные описания сохранены в подробных описаниях 55 действий. Проверка работает по структуре данных, не по списку названий. Длительности, условия, ресурсы, дополнительные операции, неизвестные поля, повторяемость и ссылки из других контекстов исключают автоматическое удаление.

Удаление штатное мягкое (`deleted_at`). При первоначальной локальной проверке исходники были сохранены в дополнительной локальной таблице. Для релиза этот подход заменён внешним защищённым архивом: SQL не создаёт таблиц и не изменяет схему 308. Запись требует абсолютного пути архива, точного исходного commit и ID свежей защищённой полной копии БД. Архив сохраняет рассмотренные исходные/новые значения и SHA-256 плана, имеет режим 0600 внутри каталога 0700; повтор не перезаписывает его, изменение идентичности блокируется. Полная резервная копия сохраняет все поля исходных строк. Перед первоначальным применением также сделан отдельный локальный снимок затронутых записей: `outputs/combat-repairs/action-wrappers-backup-20261008.json`. Старые боевые артефакты, события и журналы не переписываются. Прямые привязки этих эффектов в персонажах/шаблонах блокируют миграцию, чтобы не потерять действия; в проверенной локальной базе их нет.

Транзакция блокирует конкурентную запись каталога, проверяет исходники и новые входящие ссылки. Повторное применение идемпотентно. Новые исходные данные на проде потребуют повторного рассмотрения плана при несовпадении, а не перезаписи каталога.

## Подтверждение администратора

В игнорируемый `.env` этой рабочей копии записан случайный 256-битный `ADMIN_ELEVATION_PASSWORD`. Сервер получает только `ADMIN_ELEVATION_PASSWORD_HASH` (bcrypt, cost 12) через приватную локальную конфигурацию. API перезапущен; пароли аккаунтов, списки администраторов и продовая конфигурация не изменялись. Секрет не выводился в чат или логи.

## Проверка

Проверены TypeScript, 24 целевых frontend-теста и три теста миграции с разными данными вида и подкласса. Миграция применена локально дважды: повторное применение не меняет записи; 35 исходных эффектов архивированы, живых входящих ссылок на них нет. Изменённый исходник намеренно отклонён с откатом транзакции.

Браузерная проверка: отмена выбора вида и класса очищает обе панели; отмена подвида оставляет основной вид и убирает подвид. Отмена последних выбранных источников проверена повторным входом после перезагрузки. Превью находится в `body` поверх сетки. На странице драконорождённого остались строки 1 и 5 и исчез пустой столбец ресурсов; на 5-м уровне показано действие полёта без дублирующего эффекта.
