# Кандидаты на миниатюры для 3D-боёв

Исследовано 27 сентября 2026 года. Это кандидаты для художественной проверки, а не приобретённые или встроенные в игру файлы. Цель — естественная анатомия, умеренно реалистичные фактуры и читаемость на небольшом игровом поле. Текущий бестиарий: 22 записи (в том числе два служебных манекена) и три персонажа-шаблона; список хранится в `frontend/src/battle3d/miniatures/catalog.snapshot.json`.

Не стоит закрывать пробелы первым найденным мультяшным набором: будет заметен разрыв стиля.

## Источники и условия

- [Sketchfab](https://sketchfab.com/blogs/community/an-introduction-to-creative-commons-licenses/) — бесплатные модели бывают с разными условиями. Для перечисленных выше указана CC BY: нужны имя автора, ссылка на модель, лицензия и сведения об изменениях. Модели с NC или ND не подходят как общая основа для коммерческого и редактируемого продукта. [Рекомендации Sketchfab по атрибуции](https://sketchfab.com/developers/download-api/guidelines/) требуют сохранять указание автора и источника для пользователей приложения.
- [Fab Standard License](https://www.fab.com/eula) разрешает коммерческое использование и совместимые инструменты за пределами Unreal Engine, но запрещает самостоятельную перепродажу/раздачу модели. Перед публикацией платного GLB через браузер нужно отдельно оценить, не превращает ли способ доставки файл в самостоятельную раздачу; при сомнении согласовать это с продавцом. Покупать исходный формат, не Reference-Only. Страницы только с форматом Unreal Engine требуют экспорта и не дают готовой модели для Three.js.
- [Poly Haven](https://polyhaven.com/license) полезен для материалов, HDRI и деталей окружения: всё CC0. Это не полноценный каталог фэнтезийных персонажей.
- [Mixamo](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html) может дать движение двуногим персонажам после выбора внешности; Adobe разрешает использовать персонажей и анимации в играх. Автоматический риггер не рассчитан на волков и пауков.
- [Hero Forge](https://heroforge.com/content/support-docs/digital-models/) продаёт STL для печати и отдельные файлы для поддерживаемых виртуальных столов; это не подтверждённая библиотека ассетов для нашей браузерной игры. Модели Sigil, TaleSpire и Demeo используются только как художественный ориентир.

## Рекомендуемая проверка

Начать с бесплатного стражника на копии текущего боя: три экземпляра на одном поле сразу покажут реальное качество, загрузку и масштаб. Затем выбрать один согласованный платный ряд для трёх героев и основных противников, открыть реальные GLB в нашей сцене и сравнить в одинаковом освещении. Для браузера подготовить уровни детализации, уменьшенные текстуры и отдельные основания. Подмена касается только `MiniatureModel` и привязок внешности; команда, инициативный порядок и другие правила остаются в существующем движке.
