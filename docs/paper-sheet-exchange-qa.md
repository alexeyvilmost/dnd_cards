# Бумажный лист: обмен JSON, PDF и печать

Локальная проверка перед релизом: 24 сентября 2026.

## Форматы и гарантии

- JSON Bag of Holding версии 1 — основной формат резервной копии. Сохраняет формулы, ссылки библиотеки, количества, флаги, настройки и присоединённые исходные данные LSS.
- Импорт LSS поддерживает экспорт персонажа версии 2 (в том числе листы оформления 2014/2024), строковый и объектный `data`, старый необёрнутый документ и UTF-8 BOM.
- Неизменённый импортированный персонаж экспортируется с исходными данными LSS. Изменения известных полей накладываются на оригинал, не уничтожая неизвестные поля, богатый текст, ресурсы, бонусы и статусы заклинаний.
- Новые предметы и заклинания Bag of Holding передаются в LSS читаемым текстом. Наши UUID не выдаются за ID чужой библиотеки. Итоговые характеристики берутся из общего расчёта листа, включая загруженное снаряжение.
- Повреждённый JSON, слишком глубокая структура и файлы больше 10 МБ отвергаются до замены листа. Перед корректным импортом пользователь подтверждает замену.

## Важные ограничения LSS

Экспорт персонажа LSS содержит ID библиотечных заклинаний, но не обязательно их названия и определения. Неизвестные ID сохраняются и явно показываются; описание не выдумывается. Их можно сопоставить с нашей библиотекой вручную. Исходный ID при этом сохраняется для обратного обмена — это сопоставление, а не замена заклинания на другое.

Для собственных заклинаний нужно отдельно экспортировать JSON гримуара в LSS и загрузить его кнопкой «Добавить гримуар LSS». Совпадение выполняется по исходным ID. Определения хранятся в документе, доступны через каноничное превью и включаются в PDF. Ранее отредактированные пользователем поля не перезаписываются. Самостоятельный JSON персонажа LSS по-прежнему не заменяет отдельный файл гримуара.

Специфические ресурсы, бонусы и ячейки договора LSS сохраняются в оригинале, но не обещается выполнение чужих механик нашим движком. Импорт предупреждает об этом. Предметы LSS из текстового блока остаются текстом, без попытки угадать соответствие нашим предметам.

## Проверено в браузере

Все тестовые сущности имеют префикс `BOH QA`; существующие пользовательские персонажи не редактировались.

| Сценарий | Результат |
| --- | --- |
| Созданный в LSS волшебник 2024 → BOH → LSS | Имя и хиты изменены; посох, формула урона, кириллица, специальные символы и три библиотечных заклинания сохранены |
| Созданный в LSS жрец с оформлением 2014 → BOH → LSS | Снаряжение и количества, текстовые заклинания, концентрация, формулы и алмаз стоимостью 300 зм сохранены |
| Собственное заклинание LSS «Светлячок» | Экспортирован отдельный гримуар; запись сопоставлена по ID; каноничное превью показывает полный текст; повторный импорт и перезагрузка сохраняют описание |
| Новый лист BOH с библиотечными предметом и заклинанием → LSS | Хиты 24/28, 20 зелий и «Благословение» с концентрацией и материальным компонентом отображаются в LSS |
| BOH JSON → импорт → повторный экспорт | Файлы нового листа совпали по SHA-256; библиотечная ссылка открывает прежнее заклинание |
| PDF волшебника, жреца и нового листа | Все страницы преобразованы в PNG и просмотрены; кость хитов, количества, флаги и кириллица видимы; служебные элементы скрыты; длинный текст вынесен в приложение |

## Печать и автоматические проверки

PDF скачивается отдельной кнопкой, без системного диалога. PDF и печать используют общий снимок всех четырёх страниц и приложения для неуместившихся данных. Снимок не изменяет документ и выбранную вкладку. Это обычный визуальный PDF, не PDF с редактируемыми полями.

Кнопка «Печать» вызвана в браузере без ошибок. Системный диалог и физический принтер недоступны автоматизации во встроенном браузере; реальная печать на устройстве не подтверждена. Автотесты проверяют события `beforeprint`/`afterprint`, снимок скрытых страниц, текущие значения элементов, полные длинные названия и очистку после печати.

- Общий прогон frontend: 498 файлов, 4392 теста — успешно.
- После последних защитных правок: 13 файлов, 139 тестов бумажного листа — успешно.
- Проверка TypeScript и сборка Vite — успешно; стандартное предупреждение о крупных чанках.
- Реальные обезличенные тестовые экспорты лежат в `frontend/src/paper-sheet/fixtures/lss-*.json`.
