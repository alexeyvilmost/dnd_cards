# Исторический архив

Здесь сохранены завершённые и заменённые отчёты. Они описывают состояние на свою дату, включая прежние выводы и спорные оценки. Ссылки из старых документов сохраняются через перенаправляющие страницы; байты оригиналов и номера строк не меняются.

Первый перенос 04.10.2026: три июльских отчёта, которые `knowledge-base.md` уже отмечает как устаревшие или закрытые. Хэши и обратимая операция записаны в `../audits/2026-10-04/execution/document-archive-manifest.json`.

Текущие инструкции: [индекс документации](../README.md). Архив не заменяет текущие проверки и не подтверждает статус сущностей в БД.
